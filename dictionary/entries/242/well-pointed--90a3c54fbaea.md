### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Said of a category or topos&#58; that it has a terminal object (or that it has no zero object, if it is a topos) and in which any distinct pair of parallel morphisms can be distinguished by their distinct compositions with a global element of their domain; i.e. any pair of parallel morphisms is distinct if and only if there is a global element in their domain that does not equalize them.

   **Usage:** not-comparable
