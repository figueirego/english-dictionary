### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. One of a class of verbs which use a dental suffix appended to the stem to indicate the past tense.

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

   **Source context (verbatim):** in the Germanic languages

<a id="r1-s2"></a>

**Source sense R1.S2**

2. One of a class of verbs which use a dental suffix appended to the stem to indicate the past tense.
   1. A regular verb of this class (thus excluding verbs that do have a dental suffix, but show some formal peculiarity, as in tell &gt; told).

      **Usage:** by narrowing

      **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

      **Source context (verbatim):** in the Germanic languages

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A member of a verb class that is customarily called “weak”, and usually distinguished from another class called “strong”.

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

   **Source context (verbatim):** in non-Germanic languages

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A member of a verb class that is customarily called “weak”, and usually distinguished from another class called “strong”.
   1. A verb formed from a root that includes a semivowel or another consonant prone to elision (so-called “weak roots”).

      **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

      **Source context (verbatim):** in the Semitic languages; in non-Germanic languages
