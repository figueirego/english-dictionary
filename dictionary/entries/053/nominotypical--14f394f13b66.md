## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Of a subspecies&#58; nominate, having a name which repeats the species name, designating that it represents the originally described population.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** biology; botany; natural-sciences; zoology

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of a subgenus or other infrageneric taxon&#58; having a name which repeats the genus name, indicating that it includes the type species. For older botanical subgeneric and sectional names, it is sometimes prefixed with Eu-.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** biology; botany; natural-sciences; zoology
