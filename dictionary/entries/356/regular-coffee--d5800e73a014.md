## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Coffee of the sort which is considered the default in a given area&#58;
   1. Coffee with cream and sugar (in contrast to the expected meaning of "black coffee" in other regions of the US).

      **Usage:** New-England; countable; uncountable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Coffee of the sort which is considered the default in a given area&#58;
   1. Coffee with one cream and one sugar.

      **Usage:** Canada; countable; uncountable

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Coffee of the sort which is considered the default in a given area&#58;
   1. Black coffee.

      **Usage:** countable; uncountable

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Coffee of the sort which is considered the default in a given area&#58;
   1. Coffee with caffeine (as opposed to decaffeinated).

      **Usage:** countable; uncountable

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Coffee of the sort which is considered the default in a given area&#58;
   1. American coffee, as opposed to espresso, or a derived coffee drink (cappuccino, latte, iced coffee, etc).

      **Usage:** US; countable; dialectal; uncountable
