### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. The element of a set with the greatest magnitude.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r2-s2"></a>

**Source sense R2.S2**

2. Said of an ideal of a ring or a filter of a lattice&#58; that it is as large as it can be without being trivial (improper).

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r2-s3"></a>

**Source sense R2.S3**

3. Said of a set of well-formed formulas&#58; that it is as large as it can be without being inconsistent; i.e. that for any well-formed formula φ, the set contains either φ or ~φ.
