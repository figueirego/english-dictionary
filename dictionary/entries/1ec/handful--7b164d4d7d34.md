**Source sense R1.S1**

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A hand's breadth; four inches.

   **Usage:** obsolete

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A small number, usually approximately five.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A group or number of things; a bunch.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Something which can only be managed with difficulty.

   **Usage:** informal
