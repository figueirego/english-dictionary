### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. A set of glyphs of unified design, belonging to one typeface (e.g., Helvetica), style (e.g., italic), and weight (e.g., bold). Usually representing the letters of an alphabet and its supplementary characters.
   1. In metal typesetting, a set of type sorts in one size.

      **Source topics (extractor hierarchy; not curated):** media; publishing; typography

<a id="r2-s2"></a>

**Source sense R2.S2**

2. A set of glyphs of unified design, belonging to one typeface (e.g., Helvetica), style (e.g., italic), and weight (e.g., bold). Usually representing the letters of an alphabet and its supplementary characters.
   1. In phototypesetting, a set of patterns forming glyphs of any size, or the film they are stored on.

      **Source topics (extractor hierarchy; not curated):** media; publishing; typography

<a id="r2-s3"></a>

**Source sense R2.S3**

3. A set of glyphs of unified design, belonging to one typeface (e.g., Helvetica), style (e.g., italic), and weight (e.g., bold). Usually representing the letters of an alphabet and its supplementary characters.
   1. In digital typesetting, a set of glyphs in a single style, representing one or more alphabets or writing systems, or the computer code representing it.

      **Source topics (extractor hierarchy; not curated):** media; publishing; typography

<a id="r2-s4"></a>
