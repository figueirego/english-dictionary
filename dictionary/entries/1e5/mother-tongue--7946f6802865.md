### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The language one first learned; the language one grew up with; one's native language.

   **Example:** His mother tongue is a relatively conservative dialect of Aramaic.

   **Source synonyms:** first language; mother language; native language; native tongue; L1

   **Source antonyms:** father tongue

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The language spoken by one’s ancestors.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The language spoken by one's mother, when it differs from that spoken by one's father.

   **Source antonyms:** father tongue

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Informal speech, as opposed to educated language.

   **Source antonyms:** father tongue
