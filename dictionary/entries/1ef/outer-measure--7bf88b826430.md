### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A measure-like function derived from some premeasure as follows&#58; when it is applied to a set E, it yields the infimum of the premeasures of all possible premeasurable covers of E. More abstractly, a measure-like function whose domain is the power set of some underlying set, which has the properties of (1) yielding zero when applied to the empty set, (2) being monotonic (if A is subset of B then this function applied to A is less-than-or-equal to this function applied to B), (3) being subadditive (if A is a countable sum of Bⱼ's then this function applied to A is less-than-or-equal to the sum of the applications of this function to the Bⱼ's).
