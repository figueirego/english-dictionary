## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Having the property that many elements of one set may be assigned by the relationship to any element in the other set, and that a given element in the first set can also be assigned more than one member of the second set.

   **Usage:** not-comparable

   **Example:** "Is a fellow citizen with" is a many-to-many relationship on the set of people (from the set of people to the set of people).

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

   **Source context (verbatim):** of a relationship between two sets

<a id="r1-s2"></a>

**Source sense R1.S2**

2. From many sources to many recipients.

   **Usage:** not-comparable

   **Example:** The normal state of human affairs is many-to-many communications, each source going out to many recipients, but each recipient also having multiple sources.
