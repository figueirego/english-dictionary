### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The main or first page of a website or set of hyperlinked documents.

   **Usage:** Internet

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The default page set to open in a web browser or hypertext system when it starts up, or when its home function is invoked.

   **Usage:** Internet

   **Example:** A computer virus kept changing my home page to a site full of adware.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Someone's public personal home page/site on the World Wide Web.

   **Usage:** Internet

   **Example:** My home page is www.example.com/~user.
