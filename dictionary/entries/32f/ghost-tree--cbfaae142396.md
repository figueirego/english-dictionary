## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The dove tree, Davidia involucrata, which has large white bracts resembling white sheets like those used to represent ghosts.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A dead or dying tree in a relatively intact state in a ghost forest.

   **Usage:** plural; usually
