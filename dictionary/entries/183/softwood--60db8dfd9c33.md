### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The wood from any gymnosperm, without regard to its softness.

   **Usage:** uncountable

   **Source topics (extractor hierarchy; not curated):** biology; botany; natural-sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Wood of this kind, but limited to those that are commercial timbers.

   **Usage:** countable

   **Source context (verbatim):** in more general use

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The tree or tree species that yields this wood.

   **Usage:** countable

   **Example:** SYP is a softwood, but it is harder than many hardwoods.

   **Example:** This softwood has been planted extensively throughout Scotland.

   **Source topics (extractor hierarchy; not curated):** business; forestry

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Any commercial timber.

   **Usage:** uncountable

   **Example:** You should have used softwood for the frame of this shed, instead of overbuilding it like this.
