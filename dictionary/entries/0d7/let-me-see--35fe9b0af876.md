## Phrase

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Used as a filled pause to indicating thinking or pondering, not inviting hearer to participate.

   **Usage:** set phrase

   **Example:** Now, let me see. When did you want the appointment?

   **Example:** Let me see. What should I make for dinner tonight?

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used when pondering the results of an action one is doing, or to politely ask for permission to do something

   **Example:** Let me see if I can find that book for you.

   **Example:** Let me see if this microphone works.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Used to indicate incredulity; wait a minute; hold on

   **Usage:** broadly

   **Example:** Let me see if I understood you correctly.

   **Example:** Let me see if I have this straight.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Used other than figuratively or idiomatically&#58; see let, me, see.
