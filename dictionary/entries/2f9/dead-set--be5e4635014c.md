## Noun · Record 1

### Forms

- dead sets — plural
- dead-set — alternative

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The rigid pose a hunting dog assumes when pointing out game to a hunter.

   **Example:** The judge at the dog show took points off the Irish setter's dead set because its right ear twitched a few times.

   **Source topics (extractor hierarchy; not curated):** hobbies; hunting; lifestyle

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A fixed or stationary condition arising from obstacle or hindrance; a deadlock.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A determined effort.

   **Usage:** broadly; figuratively

   **Example:** I might not graduate first in my class, but I'll make a dead set at it.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A pointed and persistent attack on a person.

## Adjective · Record 2

### Forms

- more dead set — comparative
- most dead set — superlative
- dead-set — alternative

### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. Unswervingly dedicated; resolutely determined.

   **Example:** If John is dead set on marrying Catherine, his parents' objection will only provoke a falling out.

   **Example:** The governor is dead set against the concealed weapons permit legislation and will veto it even if it costs her the re-election.

   **Source synonyms:** hell-bent

<a id="r2-s2"></a>

**Source sense R2.S2**

2. Complete and utter; total.

   **Usage:** Australia; colloquial

   **Example:** He is a dead set fool.
