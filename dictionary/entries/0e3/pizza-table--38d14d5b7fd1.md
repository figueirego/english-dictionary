## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A small, inedible, table-shaped object that sits on a pizza pie and holds up the top of the box the pie lies in, preventing it from settling into the pie.

   **Usage:** idiomatic

   **Source synonyms:** box tent; package saver; pizza saver

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A table on which pizza is served or eaten.

   **Usage:** literally
