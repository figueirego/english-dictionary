**Source sense R1.S1**

1. A page larger in size than an ordinary (base) page.

   **Usage:** operating systems; especially FreeBSD; operating systems; especially FreeBSD

   **Example:** Superpage support in an operating system allows for more efficient mapping of large regions physical memory into the process address space than having to subdivide the physical memory into base pages.

   **Source synonyms:** huge page; large page
