### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To inform briefly of the main points of; to bring an idea or proposal to the attention of (especially in order to obtain their opinion of it).

   **Usage:** ditransitive

   **Example:** Let me run that idea by the board before we spend too much time on it.

   **Example:** I would like to hear your opinion on this. Have you got a few minutes, so I can run some ideas by you?

   **Example:** Can you just run those numbers by me again, please? To make sure I've got them clear.

   **Source synonyms:** run past

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To briefly stop at a location for a particular purpose.

   **Usage:** transitive

   **Example:** Can you run by the store for milk?

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Used other than figuratively or idiomatically&#58; see run, by.
