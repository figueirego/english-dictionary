### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The ability of the brain to record information or impressions with the facility of recalling them later, usually at will.

   **Usage:** uncountable

   **Example:** Memory is a facility common to all animals.

   **Source synonyms:** recall; retention

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A record of a thing or an event stored and available for later use by an organism.

   **Usage:** countable; uncountable

   **Example:** I have no memory of that event.

   **Example:** My wedding is one of my happiest memories.

   **Example:** Sam and his friends will never forget the happy memories of the field trip to France.

   **Source synonyms:** recall; recollection

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The part of a computer that stores variable executable code or data (RAM) or unalterable executable code or default data (ROM).

   **Usage:** countable; uncountable

   **Example:** This data passes from the CPU to the memory.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** core (dated)

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The time within which past events can be or are remembered.

   **Usage:** countable; uncountable

   **Example:** in recent memory

   **Example:** in living memory

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Of a material, which returns to its original shape when heated.

   **Usage:** attributive; countable; uncountable

   **Example:** memory metal

   **Example:** memory plastic

<a id="r1-s6"></a>

**Source sense R1.S6**

6. A memorial.

   **Usage:** countable; obsolete; uncountable

<a id="r1-s7"></a>

**Source sense R1.S7**

7. Synonym of pelmanism (“memory card game”).

   **Usage:** uncountable

   **Source synonyms:** pelmanism (synonym; synonym-of)

<a id="r1-s8"></a>

**Source sense R1.S8**

8. A term of venery for a social group of elephants, normally called a herd.

   **Usage:** collective; countable; rare; uncountable

   **Source topics (extractor hierarchy; not curated):** biology; natural-sciences; zoology
