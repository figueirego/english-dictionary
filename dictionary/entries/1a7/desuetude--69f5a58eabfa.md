### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The state when something (for example, a custom or a law) is no longer observed nor practised; disuse, obsolescence.

   **Usage:** formal; uncountable

   **Source synonyms:** disuse; inusitation; obsoleteness; desuetude; disusage; disuse; inusitation (archaic); obsolescence; obsoleteness; obsoletion; superannuation; unuse

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The state when something (for example, a custom or a law) is no longer observed nor practised; disuse, obsolescence.
   1. An instance of this.

      **Usage:** countable; formal

      **Source synonyms:** disuse; inusitation; obsoleteness; desuetude; disusage; disuse; inusitation (archaic); obsolescence; obsoleteness; obsoletion; superannuation; unuse

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Chiefly followed by from or of&#58; a cessation of practising or using something.

   **Usage:** countable; formal; obsolete
