### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To imprison or incarcerate (someone).

   **Usage:** transitive

   **Source synonyms:** send away; shut away

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To put (something) away in a locked location for safekeeping; (occasionally, chiefly humorously) to sequester (a person) in a similar way.

   **Usage:** transitive

   **Example:** Please lock up all valuables in the safe before leaving.

   **Example:** Angus is back in town! Better lock up your daughters, your wife, and your sheep!

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To close (and often lock) all doors and windows (of a place) securely.

   **Usage:** intransitive

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To lock (a door, window, etc.).

   **Usage:** transitive

   **Example:** That door still needs to be locked up.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To cease responding.

   **Usage:** intransitive

   **Example:** When I press this button, the program locks up.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** freeze; freeze up; hang; hang up

<a id="r1-s6"></a>

**Source sense R1.S6**

6. To cause (a program) to cease responding or to freeze.

   **Usage:** transitive

   **Example:** If your password contains a particular string of letters, entering it can lock up the login form.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
