### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A form of random access memory that requires fewer transistors per bit than SRAM, but in which each bit needs to be refreshed regularly to retain its contents.

   **Usage:** uncountable; usually

   **Example:** DRAM is typically slower but much less expensive than SRAM, and is therefore often used as the main memory in a computer system.
