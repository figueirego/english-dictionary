### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An absolute value (or norm) for a field which is defined to be equal to one for any element of the field other than the field's zero, for which it is defined to be equal to zero.

   **Example:** The trivial absolute value gives rise to the discrete metric.
