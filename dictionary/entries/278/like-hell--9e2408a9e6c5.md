## Prep\_phrase

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. In a manner that uses all of the strength, speed, or effort that a person can summon.

   **Usage:** emphatic; intensifier

   **Example:** You'd better run like hell!

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used ironically to express the opposite of one's intentions

   **Example:** Me do the washing up? Like hell I will!

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Bad or badly.

   **Example:** You look like hell!

   **Example:** It stank like hell down there!
