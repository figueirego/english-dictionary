### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To leave, to depart, to get moving.

   **Usage:** intransitive

   **Example:** It is quite late, I'd best get going before sunset.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To begin or commence.

   **Usage:** intransitive; transitive

   **Example:** We'd better get this project going. If we don't get going on it soon, we won't finish in time.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To excite intellectually.

   **Usage:** transitive

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To arouse sexually.

   **Usage:** transitive

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To talk passionately without interruption.

   **Usage:** intransitive

<a id="r1-s6"></a>

**Source sense R1.S6**

6. To cause someone to talk passionately without interruption.

   **Usage:** transitive

<a id="r1-s7"></a>

**Source sense R1.S7**

7. To cry or bawl loudly.

   **Usage:** intransitive

   **Source context (verbatim):** of a baby
