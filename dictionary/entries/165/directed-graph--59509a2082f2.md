### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A graph in which the edges are ordered pairs, so that, if the edge (a, b) is in the graph, the edge (b, a) need not be in the graph and is distinct from (a, b) if it is.

   **Example:** A directed graph (A, R) is a set of vertices A together with an incidence relation R&#58; if aRb then there is an edge going from A to B.

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences

   **Source synonyms:** digraph

   **Source antonyms:** undirected graph
