### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To set (someone or something) on fire; to cause (someone or something) to burn, flame, or glow; to kindle.

   **Usage:** transitive

   **Source synonyms:** aflame; ignite; aflame; alight; conflagrate; fire; fire up; ignite; inflame; enkindle; light; light up; set ablaze; set afire; set aflame; set alight; set fire; set on fire; torch

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To cause (something) to appear bright or red, as if on fire; to brighten, to redden.

   **Usage:** broadly; transitive

   **Source synonyms:** irritate

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To cause (the body or a body part) to feel abnormally or unusually hot; specifically (medicine), to cause inflammation, including abnormal heat, pain, redness, swelling, etc., in (the body or a body part).

   **Usage:** broadly; transitive

   **Example:** to inflame the eyes by overwork

   **Source synonyms:** irritate

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To cause (someone, or their heart, mind, etc.) to feel strong desire or other feelings; to excite (someone) to great passion; specifically, to cause (someone) to feel anger or rage; to anger, to enrage, to incense.

   **Usage:** figuratively; transitive

   **Source synonyms:** exasperate; irritate; affront; aggravate; anger; antagonize; awrath; burn up; cheese off (slang); cross; embitter; envenom; gall; get; get to; honk off; incense; inflame; infuriate; madden; make angry; nark (Australia; New-Zealand; UK; slang); offend; outrage; provoke; put out; rankle; rile; piss off; roil; set off; steam; tick off; get one's back up; get someone's dander up; get someone's goat; get someone's Irish up; make someone see red; make someone's blood boil; put someone's back up; raise someone's hackles; raise someone's shag; rattle someone's cage; rub the wrong way; ruffle some feathers; set up someone's birse (Scotland)

   **Source antonyms:** disinflame

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To excite or intensify (a feeling, such as an appetite or passion), especially to an excessive or unnatural level.

   **Usage:** figuratively; transitive

   **Example:** to inflame desire
