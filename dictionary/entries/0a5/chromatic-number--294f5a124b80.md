## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The smallest number of colours needed to colour a given graph (i.e., to assign a colour to each vertex such that no two vertices connected by an edge have the same colour).

   **Example:** The chromatic number of a complete graph K\#95;n is n; the chromatic number of a bipartite graph K\#95;\#123;n,m\#125; is 2.

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences

### Related words

**Source synonyms:** vertex chromatic number (usually) — smallest number of colours needed to colour the vertices of a graph
