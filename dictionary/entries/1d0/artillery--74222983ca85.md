### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Large projectile weapons, in modern usage usually large guns, but also rocket artillery.

   **Usage:** countable; uncountable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An army unit that uses such weapons, or a military formation using projectile weapons, such as archers.

   **Usage:** countable; uncountable

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Gunnery (design and manufacture of guns).

   **Usage:** countable; uncountable

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Weapons, especially siege engines.

   **Usage:** archaic; countable; uncountable

<a id="r1-s5"></a>

**Source sense R1.S5**

5. One or more guns.

   **Usage:** Ireland; UK; countable; slang; uncountable
