### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. In a paradoxical manner; so as to create a paradox.

   **Example:** The proliferation of labor-saving devices has not given us more leisure time, paradoxically.

   **Example:** If there exists a non-empty set of uninteresting natural numbers, there must be a smallest uninteresting number, but this number is paradoxically interesting because it is the smallest uninteresting number.
