## Noun

### Forms

- generic names — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The first word in a binominal name, which identifies the genus of the lifeform considered.

   **Example:** Its generic name is Staphylococcus, but you may know it better by the common name staph.

   **Source topics (extractor hierarchy; not curated):** biology; natural-sciences; taxonomy

   **Source synonyms:** genus name; generic epithet

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A nonproprietary name given to a drug that is used to identify it irrespective of trademark.

   **Usage:** pharmacy

   **Example:** Its generic name is rosuvastatin, but you may know it better by the proprietary name Crestor.

   **Source topics (extractor hierarchy; not curated):** medicine; pharmacology; sciences

   **Source antonyms:** trade name

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A similar nonproprietary name for any other product or service, denoting any member of the category.

   **Example:** Its generic name is flying disc, but you may know it better by the proprietary name Frisbee. The generic name frisbee (lowercase) is used informally but not officially or legally.

   **Source topics (extractor hierarchy; not curated):** business; commerce
