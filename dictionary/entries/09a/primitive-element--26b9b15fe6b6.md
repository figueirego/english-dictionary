## Noun

### Forms

- primitive elements — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An element that generates a simple extension.

   **Usage:** field theory

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An element that generates the multiplicative group of a given Galois field (finite field).

   **Usage:** field theory

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

   **Source context (verbatim):** of a finite field

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Given a modulus n, a number g such that every number coprime to n is congruent (modulo n) to some power of g; equivalently, a generator of the multiplicative field of integers modulo n.

   **Source topics (extractor hierarchy; not curated):** mathematics; number-theory; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. An element that is not a positive integer multiple of another element of the lattice.

   **Usage:** lattice theory

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

   **Source context (verbatim):** of a lattice

<a id="r1-s5"></a>

**Source sense R1.S5**

5. An element x ∈ C such that μ(x) = x ⊗ g + g ⊗ x, where μ is the comultiplication and g is an element that maps to the multiplicative identity 1 of the base field under the counit (in particular, if C is a bialgebra, g = 1).

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

   **Source context (verbatim):** of a coalgebra over an element g

<a id="r1-s6"></a>

**Source sense R1.S6**

6. An element of a free generating set of a given free group.

   **Source topics (extractor hierarchy; not curated):** group-theory; mathematics; sciences

   **Source context (verbatim):** of a free group
