### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. One of the ways something exists, or the ways a set of objects can be ordered.

   **Usage:** countable; uncountable

   **Example:** Which permutation for completing our agenda items makes the most sense?

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A one-to-one mapping from a finite set to itself.

   **Usage:** countable; uncountable

   **Example:** This permutation takes each element to the one following it, with the last mapped back to the first.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. An ordering of a finite set of distinct elements.

   **Usage:** countable; uncountable

   **Example:** There are six permutations of three elements, e.g. \{abc, acb, bac, bca, cab, cba\}.

   **Source topics (extractor hierarchy; not curated):** combinatorics; mathematics; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A transformation of a set's prime form, by applying one or more of certain operations, specifically, transposition, inversion, and retrograde.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** entertainment; lifestyle; music
