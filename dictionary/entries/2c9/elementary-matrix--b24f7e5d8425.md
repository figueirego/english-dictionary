### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A square matrix which is obtained from the identity matrix by a single elementary row (or column) operation.

   **Example:** When an elementary matrix multiplies a square matrix from the left, it applies to that matrix an elementary row operation homologous to the one that created its own self. (Likewise, when an elementary matrix multiplies a square matrix from the right, it applies to that matrix an elementary column operation homologous to the one that created its own self.)

   **Example:** If a series of elementary matrices applied to a given square matrix row-reduce it to the identity matrix, then the same series of elementary matrices applied to the identity matrix yield the inverse of the given matrix.

   **Source topics (extractor hierarchy; not curated):** linear-algebra; mathematics; sciences
