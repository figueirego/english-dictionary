### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Forming nouns that denote a type of Internet post.

   **Usage:** Internet; morpheme

   **Example:** agenda + -post → agendapost (“post promoting a political agenda”)

   **Example:** Mike + -post → Mikepost (“post about someone named Mike (a politician, fictional character etc.)”)

   **Example:** shit + -post → shitpost (“low-effort post”)

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Forming verbs that denote making a type of Internet post.

   **Usage:** Internet; morpheme

   **Example:** horny + -post → hornypost (“to make lustful posts”)
