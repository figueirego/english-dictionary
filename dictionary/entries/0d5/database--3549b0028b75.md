### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A collection of (usually) organized information in a regular structure, usually but not necessarily in a machine-readable format accessible by a computer.

   **Usage:** broadly

   **Example:** I have a database of all my contacts in my personal organizer.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A set of tables and other objects (queries, reports, forms) in the form of a structured data set.

   **Example:** The "books" database will have three tables, and the "customers" database will have two tables.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A software program (application) for storing, retrieving and manipulating such a structured data set.

   **Usage:** broadly; metonymically

   **Example:** Which database do you use&#58; MySQL or Oracle?

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A combination of such data sets and the programs for using them.

   **Usage:** broadly; metonymically

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
