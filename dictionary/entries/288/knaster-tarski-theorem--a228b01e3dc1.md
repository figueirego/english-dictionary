### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A theorem stating that, if L is a complete lattice and f &#58; L → L is an order-preserving function, then the set of fixed points of f in L is also a complete lattice. It has important applications in formal semantics of programming languages and abstract interpretation.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source synonyms:** Tarski's fixed-point theorem
