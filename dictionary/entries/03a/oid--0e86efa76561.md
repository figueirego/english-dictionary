### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Resembling; having the likeness of (usually including the concept of not being the same despite the likeness, but counterexamples exist).

   **Usage:** morpheme

   **Example:** human + -oid → humanoid

   **Example:** sterol + -oid → steroid

   **Example:** ellipse + -oid → ellipsoid

   **Example:** geo- + -oid → geoid

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of, pertaining to, or related to.

   **Usage:** morpheme; uncommon

   **Example:** lympho- + -oid → lymphoid

   **Example:** myelo- + -oid → myeloid

   **Example:** aster- + -oid → asteroid

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Added to nouns to create derogatory terms, typically referring to a particular ideology or group of people.

   **Usage:** morpheme

   **Example:** waste + -oid → wastoid

   **Example:** west + -oid → westoid

   **Example:** left + -oid → leftoid

   **Example:** right + -oid → rightoid

   **Example:** goblin + -oid → goblinoid

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Added typically to the name of an algebraic structure, to denote the horizontal categorification of that structure.

   **Usage:** morpheme

   **Example:** group + -oid → groupoid

   **Example:** ring + -oid → ringoid

   **Example:** Lie algebra + -oid → Lie algebroid

   **Example:** monoid + -oid → monoidoid
