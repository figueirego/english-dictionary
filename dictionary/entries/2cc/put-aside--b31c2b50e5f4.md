<a id="r1-s2"></a>

**Source sense R1.S2**

2. To save or keep (something) to be used at a later time.

   **Usage:** transitive

   **Example:** I try to put a few dollars aside each week, just in case I need money in an emergency.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To ignore or intentionally disregard (something), temporarily or permanently, so that more important things can occupy one's attention.

   **Usage:** transitive

   **Example:** Let's put our differences aside for the moment, and get this project finished.
