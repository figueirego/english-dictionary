   **Usage:** form-of; morpheme

   **Form of:** octa- or octo- used before a vowel

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used for the digit eight to form systematic element names of elements whose existence has been predicted, and which have not yet been given a trivial name.

   **Usage:** morpheme

   **Example:** un- (“1”) + bi- (“2”) + oct- (“8”) + -ium (element suffix) → unbioctium (“element 128”)
