## Noun · Record 1

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. (symbol&#58; ⊇) With respect to another set, a set such that each of the elements of the other set is also an element of the set.

   **Usage:** especially; also casually

   **Example:** The set of human beings is a superset of the set of human children.

   **Example:** The set of characters "LBPG" is a superset of the set of characters "PG".

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory

   **Source synonyms:** supergroup; superclass; supercategory

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Two or more different physical exercises performed back to back (i.e., without a period of rest between them). The exercises may employ the same muscle group, or opposing muscle groups.

   **Source topics (extractor hierarchy; not curated):** hobbies; lifestyle; sports; weightlifting
