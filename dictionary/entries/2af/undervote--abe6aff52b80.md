## Noun · Record 1

### Forms

- undervotes — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A vote that has been cast but that shows no legally valid preference for a candidate in an election.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A vote that has been cast which shows fewer preferences than permitted or expected. (For example, if a ballot allows the voter to vote for mayor and councillor, but the voter has only voted for mayor, leaving the councillor section blank.)

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The number of such votes in an election.
