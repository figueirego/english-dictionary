### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. (of a 3-Lie algebra) A linear endomorphism f for which there is a linear endomorphism g satisfying g(\[x,y,z\]) = \[f(x),y,z\] + \[x,f(y),z\] + \[x,y,f(z)\] for all x, y and z.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Extractor diagnostics (not usage labels):** empty-gloss; no-gloss

**Supplemental definition (evidence reviewed; source gap preserved):** Definition 2.1 gives exactly the ternary condition in the original quotation. The auxiliary map g need not equal f, which distinguishes this notion from an ordinary derivation.
