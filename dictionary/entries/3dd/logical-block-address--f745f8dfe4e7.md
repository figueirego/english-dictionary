### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An address for accessing logical blocks on a secondary storage device, expressed as an integer from 0 to n−1, where n is the number of blocks available on the device. An address under the system of logical block addressing.

   **Example:** The driver needs to send the correct logical block address to the IDE device to control where to read data from.
