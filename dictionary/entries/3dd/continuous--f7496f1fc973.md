### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Without stopping; without a break, cessation, or interruption.

   **Usage:** not-comparable

   **Example:** the continuous roar of a waterfall

   **Example:** a continuous current of electricity

   **Source synonyms:** perpetual; nonstop; incessant; ongoing

   **Source antonyms:** broken; discontinuous; discrete; intermittent; interrupted

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Without intervening space; continued.

   **Usage:** not-comparable

   **Example:** a continuous line of railroad

   **Source synonyms:** protracted; extended; connected; continued; unbroken

   **Source antonyms:** broken; disconnected; disjoint

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Not deviating or varying from uniformity; not interrupted; not joined or articulated.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** biology; botany; natural-sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Such that, for every x in the domain, for each small open interval D about f(x), there's an interval containing x whose image is in D.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences

   **Source context (verbatim):** of a function

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Such that each open set in the target space has an open preimage (in the domain space, with respect to the given function).

   **Usage:** broadly; not-comparable

   **Example:** Each continuous function from the real line to the rationals is constant, since the rationals are totally disconnected.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source context (verbatim):** of a function between two topological spaces

<a id="r1-s6"></a>

**Source sense R1.S6**

6. Expressing an ongoing action or state.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences
