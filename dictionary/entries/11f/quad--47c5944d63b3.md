### Senses

**Source sense R1.S1**

1. Involving four elements.

   **Usage:** morpheme

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used for the digit four to form systematic element names of elements whose existence has been predicted, and which have not yet been given a trivial name.

   **Usage:** morpheme

   **Example:** un- (“1”) + bi- (“2”) + quad- (“4”) + -ium (element suffix) → unbiquadium (“element 124”)

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences
