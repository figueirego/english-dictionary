### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Redundant use of words, a pleonasm, an unnecessary and tedious repetition.

   **Usage:** rhetoric; uncountable

   **Example:** It is tautology to say, "Forward Planning".

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An expression that features tautology.

   **Usage:** countable; rhetoric

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A statement that is true for all truth values of its propositional variables.

   **Usage:** countable; propositional logic

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

   **Usage:** countable; first-order logic
