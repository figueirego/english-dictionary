### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Encoded computer instructions, usually modifiable (unless stored in some form of unalterable memory such as ROM).

   **Usage:** uncountable; usually

   **Example:** Some software will only run on a particular platform.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The human beings involved in warfare, as opposed to hardware such as weapons and vehicles.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** government; military; politics; war

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Recorded music content, as opposed to the hardware necessary for reproducing it.

   **Usage:** dated; uncountable; usually; music industry

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Soft goods, such as textiles.

   **Usage:** archaic; uncountable; usually
