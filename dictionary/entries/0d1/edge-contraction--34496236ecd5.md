### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An operation performed on an edge in a graph which deletes the edge, replaces its endpoints with a single new vertex, and replaces edges incident to either endpoint with an edge incident to the new vertex.

   **Example:** Performing an edge contraction on an edge in a path graph results in a path graph with one fewer vertex.

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences
