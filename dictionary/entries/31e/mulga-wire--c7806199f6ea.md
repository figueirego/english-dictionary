### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An informal gossip network, especially in a rural area such as the outback; also, a component in the network (either a person or an imagined wire).

   **Usage:** Australia; New-Zealand; countable; uncountable

   **Source synonyms:** bush telegraph; grapevine; jungle telegraph

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A message or story transmitted through such an informal network, especially one containing false information.

   **Usage:** Australia; New-Zealand; countable; uncountable

   **Source synonyms:** mulga

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A system for long-distance communication used by Aboriginal Australians, chiefly using smoke signals; also, a message or signal sent using such a system.

   **Usage:** Australia; countable; historical; uncountable
