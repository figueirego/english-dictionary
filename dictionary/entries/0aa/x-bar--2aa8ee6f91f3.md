### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A phrase, or, equivalently, a node in a syntax tree, which consists either of&#58; (1) an adjunct and another X-bar phrase, (2) a head, X, and an optional complement, or (3) a conjunction sandwiched between two other X-bars. The X is a "pro-letter" which can be substituted by letters such as N for noun, V for verb, P for preposition, I for inflectional, etc.

   **Usage:** X-bar theory
