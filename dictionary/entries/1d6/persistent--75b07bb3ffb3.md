### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Obstinately refusing to give up or let go.

   **Example:** She has had a persistent cough for weeks.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Insistently repetitive.

   **Example:** There was a persistent knocking on the door.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Indefinitely continuous.

   **Example:** There have been persistent rumours for years.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Lasting past maturity without falling off.

   **Example:** Pine cones have persistent scales.

   **Source topics (extractor hierarchy; not curated):** biology; botany; natural-sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Of data or a data structure&#58; not transient or temporary, but remaining in existence after the termination of the program that creates it.

   **Example:** Once written to a disk file, the data becomes persistent&#58; it will still be there tomorrow when we run the next program.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s6"></a>

**Source sense R1.S6**

6. Describing a fractal process that has a positive Brown function

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s7"></a>

**Source sense R1.S7**

7. non-transient.

   **Usage:** stochastic processes

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source context (verbatim):** of a state
