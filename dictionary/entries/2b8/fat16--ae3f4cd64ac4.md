## Noun

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The version of the FAT series of file systems which uses a 16-bit file allocation table.
   1. The original version of this file system, storing both the number of (real or virtual) disk sectors and the number of sector clusters in a volume as 16-bit integers.

      **Usage:** uncountable; very strictly

      **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The version of the FAT series of file systems which uses a 16-bit file allocation table.
   1. FAT16B, the version of this file system storing the number of clusters in a volume as a 16-bit integer but using a 32-bit integer to represent the total number of sectors in a volume, allowing for larger volume and file sizes.

      **Usage:** often; uncountable

      **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
