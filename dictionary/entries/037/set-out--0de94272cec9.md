### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To explain something, or give exact details, usually in writing.

   **Usage:** transitive

   **Example:** This contract sets out all the terms of the agreement as we discussed.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To go out, leave.

   **Usage:** intransitive

   **Example:** Tomorrow we set out for America.

   **Source synonyms:** set forth; take out

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To start an activity with the intention of finishing it.

   **Usage:** intransitive

   **Example:** He set out with the aim of writing the book in less than 3 months.

   **Example:** Many young people set out to change the world.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To position, to put in a position

   **Usage:** UK; transitive

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To arrange the necessary type into a printing press in preparation to run it.

   **Usage:** obsolete; transitive

   **Source topics (extractor hierarchy; not curated):** media; printing; publishing
