## Noun

### Forms

- commutators — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An electrical switch, in a generator or motor, that periodically reverses the direction of an electric current.

   **Source synonyms:** rheotrope (dated); electrepeter (dated)

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A binary map in a given group G, given by \[g, h\] = ghg⁻¹h⁻¹, where g and h are elements of G, which yields the group's identity if and only if the group operation commutes for g and h.

   **Source topics (extractor hierarchy; not curated):** group-theory; mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A binary map in a given ring R, given by \[a, b\] = ab − ba, where a and b are elements of R, which yields the ring's zero element if and only if the multiplication operation commutes for a and b.

   **Usage:** ring theory
