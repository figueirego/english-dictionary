## Noun

### Forms

- system calls — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A function provided by an operating system to allow userspace programs access to privileged features, such as accessing the system's hardware.

   **Example:** The OS provides a system call to open a file, returning file descriptor that can be used to access it.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A particular invocation of an operating-system-provided system-call function.

   **Example:** After a system call, control is returned to the process.
