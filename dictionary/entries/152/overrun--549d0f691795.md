### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To defeat an enemy and invade in great numbers, seizing the enemy positions conclusively.

   **Usage:** transitive

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To infest, swarm over, flow over.

   **Usage:** transitive

   **Example:** The cathedral square was overrun with tourists.

   **Example:** The vine overran its trellis; the field is overrun with weeds.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To run past; to run beyond.

   **Usage:** transitive

   **Example:** The athlete overran the finish line and kept going.

   **Example:** One line overruns another in length.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To run past; to run beyond.
   1. To run past the end of.

      **Usage:** transitive

      **Example:** The aircraft didn't stop in time and overran the runway.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To continue for too long.

   **Usage:** intransitive

   **Example:** The performance overran by ten minutes, which caused some people to miss their bus home.

   **Source synonyms:** run over

<a id="r1-s6"></a>

**Source sense R1.S6**

6. To carry (some type, a line or column, etc.) backward or forward into an adjacent line or page.

   **Usage:** transitive

   **Source topics (extractor hierarchy; not curated):** media; printing; publishing

   **Source synonyms:** run over

<a id="r1-s7"></a>

**Source sense R1.S7**

7. To go beyond; to extend in part beyond.

   **Usage:** transitive

   **Example:** In machinery, a sliding piece is said to overrun its bearing when its forward end goes beyond it.

<a id="r1-s8"></a>

**Source sense R1.S8**

8. To abuse or oppress, as if by treading upon.

   **Usage:** transitive

   **Source synonyms:** run over
