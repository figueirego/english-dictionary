### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An area allocated for someone to work in, especially in an office.

   **Usage:** countable; usually

   **Source synonyms:** workstation

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A file (or system of files) in which related software and data can be manipulated or developed in isolation from others.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. An empty portion of the screen or window that serves as a container for other windows or objects.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; graphical-user-interface; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Any of the screens that can be switched between in a virtual desktop.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; graphical-user-interface; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s5"></a>
