## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any machine operated by placing money or a token into a slot, especially&#58;
   1. A machine so operated to play games of chance for money, especially those with a lever and three or more rollers used to achieve combinations.

      **Usage:** UK; US

      **Source synonyms:** one-armed bandit; slot; fruit machine; poker machine; pokie; pokie machine

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Any machine operated by placing money or a token into a slot, especially&#58;
   1. Synonym of vending machine.

      **Source synonyms:** vending machine (synonym; synonym-of)
