### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Referring back to the subject, or having an object equal to the subject.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of a relation R on a set S, such that xRx for all members x of S (that is, the relation holds between any element of the set and itself).

   **Usage:** not-comparable

   **Example:** "Equals" is a reflexive relation, as it holds for all possible x; "not less" is non-reflexive because it is true only for some x and y, "unequal" is irreflexive, as it never holds between x and itself.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Of or resulting from a reflex.

   **Usage:** not-comparable

   **Example:** The electric shock elicited an automatic and reflexive response from him.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Producing immediate response, spontaneous.

   **Usage:** figuratively; not-comparable

   **Example:** a reflexive dislike

   **Source antonyms:** contemplative; considered

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Producing or provoking a reciprocal response.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** government; politics

<a id="r1-s6"></a>

**Source sense R1.S6**

6. Synonym of reflective.

   **Usage:** not-comparable

   **Source synonyms:** reflective (synonym; synonym-of)
