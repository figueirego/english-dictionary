### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Behaving similarly to Unix. Often used to describe systems which do not qualify for use of the Unix trademark.

   **Example:** NetBSD provides its users with a free Unix-like system.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Having design principles consistent with those of Unix.

   **Example:** This program is much more Unix-like&#58; it operates on standard I/O instead of prompting the user for filenames.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
