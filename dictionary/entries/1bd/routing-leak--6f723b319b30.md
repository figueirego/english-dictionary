### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The situation where the internal routing table of a network provider is broadcast externally to peered networks via Border Gateway Protocol (usually caused by an error in a boundary router), resulting in incorrectly routed internet traffic for external networks which accept the new routing instruction into their own routing tables.

   **Usage:** Internet
