**Source sense R1.S1**

   **Usage:** transitive

   **Example:** Can anyone here compute the square root of 10201?

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To make sense. (commonly used in mimicry of a science fictional robot and spoken in a robotic voice; most frequently in negative constructs)

   **Usage:** informal; intransitive

   **Example:** Does that compute, or do I need to explain further?

<a id="r2-s1"></a>

**Source sense R2.S1**

1. Computational processing power (number of operations per unit of time) or computational work (to be) done (number of operations).

   **Usage:** uncountable; chiefly cloud computing

   **Example:** The GPU does not have enough on-chip SRAM memory for the parameters, and doesn't have enough compute to run the entire model in real time.
