### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The connective "exclusive or". One way to state its meaning in plain English is "if either A or B, but not if both."

   **Example:** The XOR of (0,0) is 0; (0,1) is 1; (1,0) is 1; and (1,1) is 0.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A logic gate that implements "exclusive or".

   **Source topics (extractor hierarchy; not curated):** business; electrical; electrical-engineering; electricity; electromagnetism; energy; engineering; natural-sciences; physical-sciences; physics

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The symbolic representation that implements "exclusive or".

   **Example:** XOR can be used to add bits without carrying.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences
