**Source sense R1.S1**

1. A code C is propelinear if, for every codeword x in C, there exists a coordinate permutation Pₓ such that x + Pₓ (C) = C and, for any codewords x, y, z, and c in C, if x + Pₓ(y) = z, then P\_z(c) is the composition of the permutations Pₓ and P\_y(c).
