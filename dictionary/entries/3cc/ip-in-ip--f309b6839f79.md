### Senses

**Source sense R1.S1**

1. A protocol for sending IP packets over an existing IP network.

   **Usage:** Internet; uncountable

   **Example:** IP in IP is an unusual mechanism&#58; not only does it use two network layers, it uses the same protocol on both.

   **Example:** Although IP in IP incurs an overhead, as the size of the headers is doubled, it may allow you to create a connection between two hosts that would otherwise be blocked by a firewall.
