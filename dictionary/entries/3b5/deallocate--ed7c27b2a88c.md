### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To remove from the set of resources put aside for (allocated to) a particular user or purpose.

   **Usage:** transitive

   **Example:** Empty out your locker; it will be deallocated at the end of the day.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To return previously allocated memory.

   **Usage:** transitive

   **Example:** Computer programs should deallocate memory they no longer need, releasing it back to the system.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
