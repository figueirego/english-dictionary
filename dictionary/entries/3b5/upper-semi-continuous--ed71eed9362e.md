## Adjective

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Such that, for each fixed number, the subspace of points whose images are at least that number is closed.

   **Usage:** not-comparable

   **Source context (verbatim):** of a real-valued function on a topological space

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Such that for each fixed point x there is some neighborhood whose image's limit superior is x's image.

   **Usage:** not-comparable

   **Source context (verbatim):** of a real-valued function on a topological space
