### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To start a computer using its bootstrap procedure.

   **Usage:** transitive

   **Source synonyms:** boot; deadstart (dated; transitive)

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To start, using its bootstrap procedure.

   **Usage:** intransitive

   **Example:** It takes a couple of minutes for the computer to boot up.

   **Source context (verbatim):** of a computer

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To start a computer program or a recording of a movie, show or song.

   **Usage:** transitive

   **Example:** Then you should boot up your word processor.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To start up, to bootstrap (any process, especially a business).

   **Usage:** ambitransitive; broadly; figuratively

   **Example:** They believe they now have enough capital to boot up and stay alive until sales revenue begins.
