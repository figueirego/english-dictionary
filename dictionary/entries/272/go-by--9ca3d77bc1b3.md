## Verb

### Forms

- goes by — present; singular; third-person

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To pass or go past without much interaction.

   **Usage:** intransitive

   **Example:** I like to sit and watch the world go by. The rest of the day went by quickly.

   **Source synonyms:** pass by; go by; fly by (idiomatic); forpass (obsolete); forthglide (obsolete); overgo (UK; dialectal); pass; pass by; roll on; slip by; transpass (obsolete)

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To be called, to use as a name.

   **Usage:** transitive

   **Example:** His full name is Ernest Tinkleton, but he goes by Ernie.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To suggest or request that other people use a specific set of gender pronouns when referring to the subject.

   **Usage:** transitive

   **Example:** I go by they/them pronouns.

   **Source context (verbatim):** with gender pronouns as object

   **Source synonyms:** use

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To follow; to assume as true for the purposes of making a decision, taking an action, etc.

   **Usage:** transitive

   **Example:** I'm only going by what my teacher said.

   **Example:** a good rule to go by

   **Source synonyms:** go off
