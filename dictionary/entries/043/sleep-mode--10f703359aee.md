### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. the state of a computer system in which the drives and interfaces are switched off, and the only task running is monitoring external activity, particularly awaiting a keypress which restores the system to its active state from the random access memory.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
