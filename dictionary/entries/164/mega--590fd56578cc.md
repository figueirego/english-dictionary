### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Very large, great.

   **Usage:** morpheme; originally

<a id="r1-s2"></a>

**Source sense R1.S2**

2. In the International System of Units and other metric systems of units, multiplying the unit to which it is attached by one million (10⁶).

   **Usage:** morpheme

   **Source synonyms:** million; mul&#58;M

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Multiplying the unit to which it is attached by 2²⁰ (= 1,048,576, the binary number closest to a million). Computing symbol&#58; Mi.

   **Usage:** morpheme

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Usage:** morpheme

   **Source topics (extractor hierarchy; not curated):** business; computing; engineering; marketing; mathematics; natural-sciences; physical-sciences; sciences
