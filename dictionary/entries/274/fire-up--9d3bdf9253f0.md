### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To ignite.

   **Usage:** transitive

   **Example:** Let's fire up the grill and have a barbecue.

   **Source synonyms:** inflame; kindle; aflame; alight; conflagrate; fire; fire up; ignite; inflame; enkindle; light; light up; set ablaze; set afire; set aflame; set alight; set fire; set on fire; torch

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of an engine or similar, to start.

   **Usage:** intransitive

   **Example:** The generator fired up shortly after the power failure began.

   **Source synonyms:** fire; start up

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To launch; to run.

   **Usage:** informal; transitive

   **Example:** Fire up a text editor.

   **Example:** Fire up your computer.
