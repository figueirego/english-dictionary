## Noun · Record 1

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Text or any data that is to be encrypted (as opposed to ciphertext).

   **Usage:** uncountable

   **Example:** Using the sophisticated code was useless since the spy merely stole the plain text from the waste basket.

   **Source topics (extractor hierarchy; not curated):** computing; cryptography; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Human readable text which consists only of a string of characters, represented using a character encoding such as ASCII or Unicode. In the file format sense, plain text may represent structured data in a human readable format such as XML.

   **Usage:** uncountable; file format

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Data which consists only of human-readable unformatted text, as opposed to machine-readable binary data or formatted/structured text. In this sense, the character data in between XML tags may be called "plain text".

   **Usage:** uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
