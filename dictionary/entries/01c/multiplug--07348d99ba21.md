### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An electric device that allows more than one plug to connect to a single socket by containing multiple similar sockets; particularly for mains electricity.

   **Example:** I need to get a multiplug as I'm already using all of my sockets.
