### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Consisting of parts arranged in a single line.

   **Usage:** not-comparable

   **Source synonyms:** aligned

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Having all cylinders in a single straight line; straight.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** engineering; natural-sciences; physical-sciences

   **Source context (verbatim):** of an internal-combustion engine

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Inserted in the flow of a text.

   **Usage:** not-comparable

   **Example:** An in-line mathematical formula does not have to be on a line of its own.

   **Example:** Parenthetical referencing is a citation style which uses in-line citations enclosed within parentheses.

   **Source topics (extractor hierarchy; not curated):** communications; journalism; literature; media; publishing; writing

   **Source synonyms:** in-text

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Of a different language than the outer enclosing code.

   **Usage:** not-comparable

   **Example:** BBC BASIC allows the programmer to write in-line assembly language.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source context (verbatim):** of source code
