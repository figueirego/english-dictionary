### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To store in a file; to get rid of a document by placing it in a file or other storage.

   **Usage:** transitive

   **Example:** Would you help me file away these reports?

   **Source synonyms:** archive

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To cause oneself to remember (something); to avoid expressing a feeling, fact or idea until an appropriate time.

   **Usage:** idiomatic; transitive

   **Example:** His words hurt, but I'll file away my emotions until I can get my revenge.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To move away in a file.

   **Usage:** intransitive

   **Example:** The soldiers filed way at a quick pace.
