### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A virtual method having no implementation in a particular class, thus making the class abstract and uninstantiable. It can be overridden in subclasses.

   **Usage:** object-oriented programming

   **Source synonyms:** pure virtual function
