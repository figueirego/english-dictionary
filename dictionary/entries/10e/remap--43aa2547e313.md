### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To assign differently; to relabel or repurpose.

   **Usage:** transitive

   **Example:** He remapped the variable in the code to hold the value directly, instead of a pointer to the value.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To map again.

   **Usage:** transitive

   **Example:** Because the topography and development of the land changed so much in the floods, the region had to be remapped.
