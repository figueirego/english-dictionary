### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To delay or obstruct.

   **Usage:** transitive

   **Example:** I expect it will set us back by a day or so, but I think a side trip will be worthwhile.

   **Example:** Having the mindset that you "can't" reach your goals is only going to set you back.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To remove from or allow distance.

   **Usage:** transitive

   **Example:** Set it back from the road by twenty or thirty feet.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To install or position behind a boundary or surface, or in a recess.

   **Usage:** transitive

   **Example:** The statue was set back in a niche.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To cost money.

   **Usage:** idiomatic; transitive

   **Example:** How much do you suppose that fancy dress set her back?

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To reverse, go backwards.
