**Source sense R1.S1**

1. Unicode Transformation Format-16; a Unicode encoding scheme which uses two-byte (16-bit) code units (singly for characters in plane 0, and in four-byte \[32-bit\] surrogate pairs for supplementary characters in planes 1 through 16).
