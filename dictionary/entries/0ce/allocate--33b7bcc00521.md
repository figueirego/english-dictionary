### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To set aside for a purpose.

   **Example:** Please do not eat the meringue, as it is allocated for the dinner party tomorrow.

   **Source synonyms:** appropriate; earmark; allocate; appropriate; shelve; assign; dedicate; detach; designate; earmark; preselect; put aside; secern (archaic); secernate (archaic); separate (obsolete); sepose (obsolete); sequester; set apart; set aside

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To distribute according to a plan, generally followed by the adposition to.

   **Example:** The bulk of K–12 education funds are allocated to school districts that in turn pay for the cost of operating schools.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To reserve a portion of memory for use by a computer program.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source antonyms:** free; deallocate
