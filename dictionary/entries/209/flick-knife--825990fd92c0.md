### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A type of knife which has the blade mounted on a pivot so that it can fold back sideways into the handle when not in use, but can flick out straight, usually with a spring-loaded mechanism, when required.

   **Usage:** Ireland; UK

   **Source synonyms:** switchblade; flicky

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A type of folding knife, which with a flick of the wrist, using the momentum generated, can open the knife out straight.
