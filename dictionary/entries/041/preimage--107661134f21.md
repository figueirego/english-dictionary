### Senses

**Source sense R1.S1**

1. For a given function, the set of all elements of the domain that are mapped into a given subset of the codomain; (formally) given a function ƒ &#58; X → Y and a subset B ⊆ Y, the set ƒ⁻¹(B) = \{x ∈ X &#58; ƒ(x) ∈ B\}.

   **Example:** The preimage of \#92;\#123;4,9\#92;\#125; under the function f\#58;\#92;R\#92;rightarrow\#92;R\#58;f(x)\#61;x² is the set \#92;\#123;-3,-2,\#43;2,\#43;3\#92;\#125;.
