### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A directed acyclic graph whose vertices represent random variables and whose directed edges represent conditional dependencies. Each random variable can fall into any of at least two mutually disjoint states, and has a probability function which takes as inputs the states of its parent nodes and returns as output the probability of being in a certain state for a given combination of the states of its parent nodes. A node without parent nodes just has an unconditioned probability of being in some given state.
