## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An object within a category which sends out arrows to all other objects in that category, and such that each of these arrows is unique.

   **Example:** In the category of sets, the initial object is the empty set, since there exists a unique function, namely the empty function, from the empty set into any other given set.
