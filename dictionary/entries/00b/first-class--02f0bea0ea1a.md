### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Belonging to the best or top group in a system of classification.

   **Usage:** not-comparable

   **Example:** That was a first class restaurant.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of, or relating to the most luxurious and expensive class of accommodation on a train, ship, hotel, etc.

   **Usage:** not-comparable

   **Example:** We travelled first class to New York.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Of, or relating to a class of mail to be delivered before second class.

   **Usage:** not-comparable

   **Example:** First class stamps are now more expensive.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Great, very enjoyable.

   **Usage:** India; UK; not-comparable

   **Example:** \- How was your holiday? - It was first class.
