**Source sense R1.S1**

   **Usage:** uncountable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A solitaire game using the same tiles, where the player wins by removing pairs of matching exposed tiles until none remain.

   **Usage:** uncountable
