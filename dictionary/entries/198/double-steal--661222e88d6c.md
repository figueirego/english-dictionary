### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A situation in which two baserunners attempt to steal a base simultaneously. This is usually called by the manager when there are runners on first base and second base.

   **Example:** The team is known to try the double steal because it has so many speedsters.

   **Source topics (extractor hierarchy; not curated):** ball-games; baseball; games; hobbies; lifestyle; sports

<a id="r1-s2"></a>

**Source sense R1.S2**

   **Example:** This pair have seven double steals this season.
