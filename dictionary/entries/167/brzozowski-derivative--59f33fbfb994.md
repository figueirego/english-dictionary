### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The set of all strings obtainable from a given set of strings by cutting off a prefix. For example, for the set \{ cat, cow, dog \}, the Brzozowski derivative with respect to c is \{ at, ow \}. They have applications in regular expressions.
