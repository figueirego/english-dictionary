## Adverb

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Please, kindly; used in giving a non-concrete instruction.

   **Example:** But imagine, if you will, a world where these logistical problems were solved.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. So to speak, like; used to indicate that a description is not standard.

   **Example:** These are "partial artifacts", if you will&#58; the imaging process has merely amplified flaws that were already present in the original.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Used in conceding a description or choice of terms.

   **Example:** He wasn't a very honest person; a liar, if you will.
