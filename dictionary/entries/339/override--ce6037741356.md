## Verb · Record 1

### Pronunciation

- IPA: /əʊ.vəˈɹaɪd/ — source labels: UK
- IPA: /oʊ.vɚˈɹaɪd/ — source labels: US

### Forms

- overrides — present; singular; third-person
- overriding — participle; present
- overrode — past
- overridden — participle; past

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To ride across or beyond something.

   **Usage:** transitive

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To ride over the top of something, usually forcibly.

   **Usage:** transitive

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To ride a horse too hard.

   **Usage:** transitive

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To counteract the normal operation of something; to countermand with orders of higher priority.

   **Usage:** intransitive; transitive

   **Example:** In automotive design, safety should override lesser factors such as cosmetics and corner-cutting.

   **Example:** Congress promptly overrode the president's veto, passing the bill into law.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To give commands of a higher priority to an automated system; to take manual control of an automated system

   **Usage:** transitive

   **Example:** Manual controls allow the user to override the camera's default settings.

<a id="r1-s6"></a>

**Source sense R1.S6**

6. To define a new behaviour of a method by creating the same method of the superclass with the same name and signature.

   **Usage:** transitive; object-oriented programming

   **Example:** How the cat runs is defined in the method run() of the class Cat, which overrides the same method with the same signature of superclass called Mammal.
