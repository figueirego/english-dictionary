## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Having the property that the same argument may yield multiple values, but different arguments never yield the same value.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source context (verbatim):** of a function

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Having the property that an element of one set may be assigned by the relationship to several elements in the other set, but that a given element in the second set can have only one member of the first set assigned to it.

   **Usage:** not-comparable

   **Example:** "Being a genetic mother of" is a one-to-many relation from the set of cats to the set of cats.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

   **Source context (verbatim):** of a relationship between two sets

<a id="r1-s3"></a>

**Source sense R1.S3**

3. From a single source to multiple recipients.

   **Usage:** not-comparable

   **Example:** Traditional mass media, both print and broadcast, are forms of one-to-many communications.
