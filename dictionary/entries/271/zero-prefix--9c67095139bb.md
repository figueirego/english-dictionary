### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The digit 0 that begins all telephone numbers in the United Kingdom, which is substituted for the country code in the event of international calls.

   **Usage:** UK

   **Source topics (extractor hierarchy; not curated):** communications; electrical-engineering; engineering; natural-sciences; physical-sciences; telecommunications; telephony

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A prefix which is a null morpheme, used in models of linguistic analysis to represent the lack of a prefix where one might otherwise be expected (for example, as one of several inflections that a stem can take, or the reduction of a historically vocalised prefix to the point that it is inaudible).

   **Source topics (extractor hierarchy; not curated):** human-sciences; linguistic-morphology; linguistics; morphology; sciences

   **Source synonyms:** null prefix
