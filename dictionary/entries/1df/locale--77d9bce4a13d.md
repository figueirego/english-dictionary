### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The place where something happens.

   **Example:** Being near running water and good shade, the explorers decided it was a good locale for setting up camp.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The set of settings related to the language and region in which a computer program executes. Examples are language, currency and time formats, character encoding etc.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A partially ordered set with the following additional axiomatic properties&#58; any finite subset of it has a meet, any arbitrary subset of it has a join, and distributivity, which states that a binary meet distributes with respect to an arbitrary join. (Note&#58; locales are just like frames except that the category of locales is opposite to the category of frames.)

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences
