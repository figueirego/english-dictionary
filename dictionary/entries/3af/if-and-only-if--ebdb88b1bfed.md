### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Is equivalent to; implies and is implied by; is true and false in the same cases as.

   **Example:** A rectangle is a square if and only if all four of its sides have the same length.

   **Example:** An integer is even if and only if its square is also even.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences
