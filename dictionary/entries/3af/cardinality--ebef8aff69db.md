### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The number of elements a given set contains.

   **Usage:** countable; uncountable

   **Example:** The empty set has a cardinality of zero.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory

   **Source context (verbatim):** of a set

   **Source synonyms:** power

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The number of terms that can inhabit a type; the possible values of a type.

   **Usage:** countable; uncountable; type theory

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The property of a relationship between a database table and another one, specifying whether it is one-to-one, one-to-many, many-to-one, or many-to-many.

   **Usage:** countable; uncountable; data modeling

   **Source topics (extractor hierarchy; not curated):** computing; databases; engineering; mathematics; natural-sciences; physical-sciences; sciences
