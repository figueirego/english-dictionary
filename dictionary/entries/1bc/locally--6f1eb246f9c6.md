### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. With respect to place; in place.

   **Example:** These things are locally separated.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. In or from the local area.

   **Example:** We live locally, so I always bank locally.

   **Example:** In this shop we only sell products farmed locally.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. In a restricted part of the body.

   **Example:** To be applied locally

   **Source topics (extractor hierarchy; not curated):** medicine; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Within a sufficiently small sphere (or circle or interval) around a given point (sometimes, around any point).

   **Example:** locally Euclidean

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences
