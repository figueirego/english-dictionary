## Noun

### Forms

- extensionalities — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The principle that objects are equal if and only if their observed properties are the same, regardless of internal processes that lead to those properties.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** human-sciences; philosophy; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The principle that functions are equal if and only if they operate on the same domain and for any given element of the domain the result of each of the functions is the same.

   **Usage:** uncountable; usually; functional analysis

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The principle, codified in the axiom of extensionality, that sets are equal if and only if they contain the same elements.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory
