<a id="r1-s1"></a>

**Source sense R1.S1**

1. A chemical element (symbol Ti), atomic number 22; it is a strong, corrosion-resistant transition metal, used to make light alloys for aircraft etc.

   **Usage:** countable; uncountable

   **Example:** This airframe uses titanium alloys extensively.
