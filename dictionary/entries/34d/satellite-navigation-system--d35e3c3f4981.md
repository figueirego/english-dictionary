## Noun

### Forms

- satellite navigation systems — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any electronic navigation system which uses space satellites as radio signal sources and position references.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A satellite network used for implementing such a system.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A navigation device that implements access to such a system, having satellite signal receivers to access the satellite network.
