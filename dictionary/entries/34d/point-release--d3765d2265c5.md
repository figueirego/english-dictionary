## Noun

### Forms

- point releases — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A software release that is only slightly different from a previous version and thus having the same major version number, only differing in minor version number (after the decimal point).

   **Example:** Between 2.0 and 3.0, there were four point releases, called 2.1, 2.2, 2.3, and 2.4.

   **Example:** The company will fix the crashing issue in an upcoming point release.
