### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A metal bar on a motorcycle used to start its engine.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An act of starting a motorcycle by quickly depressing the kick start with one's foot.

   **Example:** The motorcycle requires a kick start.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A fast or strong start; help with starting or beginning well.

   **Usage:** figuratively

   **Example:** As a kick start for the group, let's write up some ideas.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. An impetus that starts or restarts some process.
