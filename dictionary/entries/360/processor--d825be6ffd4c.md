### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A person or institution who processes things (foods, photos, applications, etc.).

   **Example:** He is a loan processor with a bank.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A device which processes, which changes something (a computer processor, food processor, etc.).

   **Example:** The food processor shredded the vegetables.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A central processing unit.

   **Example:** This mainframe's processor is fast.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A microprocessor.

   **Example:** This computer has two processors, but only one keyboard.
