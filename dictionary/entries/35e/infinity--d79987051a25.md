### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Endlessness, unlimitedness, absence of a beginning, end or limits to size.

   **Usage:** uncountable

   **Example:** concept of infinity

   **Example:** The desert stretched out toward the horizon as if into infinity.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A number that has an infinite numerical value that cannot be counted.

   **Usage:** countable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source synonyms:** mul&#58;∞

<a id="r1-s3"></a>

**Source sense R1.S3**

3. An idealised point which is said to be approached by sequences of values whose magnitudes increase without bound.

   **Usage:** countable

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences; topology

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A number which is very large compared to some characteristic number. For example, in optics, an object which is much further away than the focal length of a lens is said to be "at infinity", as the distance of the image from the lens varies very little as the distance increases further.

   **Usage:** uncountable

<a id="r1-s5"></a>

**Source sense R1.S5**

5. The symbol ∞.

   **Usage:** countable; uncountable
