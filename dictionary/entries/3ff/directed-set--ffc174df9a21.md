### Senses

**Source sense R1.S1**

1. A set equipped with a preorder such that for any two elements a and b there is an element c such that a ≤ c and b ≤ c.

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences; set-theory
