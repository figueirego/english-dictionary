### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Up to the time of (something happening); pending.

   **Example:** If you can wait until after my meeting with her, we'll talk then.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Up to (a certain place)

   **Example:** Keep walking until the second set of traffic lights, then turn left.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Before (a time).

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To; physically towards.

   **Usage:** obsolete

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Up to the time that the foods or other things available to sell, or tasks which need to be completed, run out.

   **Source context (verbatim):** without an object
