### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To introduce (something) between other things; especially to insert (possibly spurious) words into a text.

   **Usage:** intransitive; transitive

   **Example:** in verse 74, the second line is clearly interpolated, probably by some unknown medieval scribe

   **Example:** When interpolating an explanatory gloss, please enclose it in square brackets to make clear that it is interpolated.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To estimate the value of a function between two tabulated points.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. During the course of processing some data, and in response to a directive in that data, to fetch data from a different source and process it in-line along with the original data.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
