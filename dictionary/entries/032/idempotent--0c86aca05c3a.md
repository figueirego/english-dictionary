## Adjective · Record 1

### Pronunciation

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. (said of a function) Such that, when performed multiple times on the same subject, it has no further effect on its subject after the first time it is performed.

   **Usage:** not-comparable

   **Example:** A projection operator is idempotent.

   **Example:** An HTTP request using the PUT verb should be idempotent, so that it can be sent to the server any number of times with the same end result.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. (said of an element of an algebraic structure with a binary operation, such as a group or semigroup) Such that, when it operates on itself, the result is equal to itself.

   **Usage:** not-comparable

   **Example:** Every finite semigroup has an idempotent element.

   **Example:** Every group has a unique idempotent element&#58; namely, its identity element.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. (said of a binary operation) Such that all of the distinct elements it can operate on are idempotent (in the sense given just above).

   **Usage:** not-comparable

   **Example:** Since the AND logical operator is commutative, associative, and idempotent, it distributes with respect to itself.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. (said of an algebraic structure) Having an idempotent operation (in the sense given above).

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences
