### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An organizer that papers are kept in, usually with an index tab, to be stored as a single unit in a filing cabinet.

   **Example:** I keep all my schoolwork in a yellow folder.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A virtual container in a computer's file system, in which files and other folders may be stored. The files and subfolders in a folder are usually related.

   **Example:** My essays are in the folder named "Schoolwork".

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** directory

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A machine or person that folds things.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A folding knife, typically a folding pocketknife.
