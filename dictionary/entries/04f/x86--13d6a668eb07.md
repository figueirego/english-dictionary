## Proper noun

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any of a family of instruction set architectures based on that used by the Intel 8086 microprocessor.
   1. Specifically, the 32-bit version of the x86 instruction set architecture.

      **Example:** The x86 version of Windows 7 only supports a maximum of 4 GiB of RAM; 64-bit Windows can support a lot more.

      **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**
