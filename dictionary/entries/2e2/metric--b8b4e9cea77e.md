## Noun · Record 2

### Pronunciation

- IPA: /ˈmɛt.ɹɪk/ — variety unspecified in the source labels

### Forms

- metrics — plural

### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. A way to measure something; a means of deriving a quantitative measurement or approximation for otherwise qualitative phenomena (especially used in engineering).

   **Example:** What metric should be used for performance evaluation?

   **Example:** What are the most important metrics to track for your business?

   **Example:** It's the most important single metric that quantifies the predictive performance.

   **Example:** How to measure marketing? Use these key metrics for measuring marketing effectiveness.

   **Example:** There is a lack of standard metrics.

   **Source synonyms:** measure

<a id="r2-s2"></a>

**Source sense R2.S2**

2. Ellipsis of metric system.

   **Usage:** abbreviation; alt-of; ellipsis

   **Alternative form of:** [metric system](../304/metric-system--c1124f968683.md)

<a id="r2-s3"></a>

**Source sense R2.S3**

3. A function which satisfies a particular set of formal conditions, created to generalize the notion of the distance between two points. Formally, a real-valued function d on M×M, where M is a set, is called a metric if (1) d(x,y)=0 if and only if x=y, (2) d(x,y)=d(y,x) for all pairs (x,y), and (3) d obeys the triangle inequality.

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences

   **Source synonyms:** distance function

<a id="r2-s4"></a>

**Source sense R2.S4**

4. A metric tensor.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences
