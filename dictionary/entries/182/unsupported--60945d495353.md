### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Without physical support.

   **Example:** The bombed bridge was left unsupported and soon collapsed.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. For which support or help is not available.

   **Example:** This obsolete software is unsupported. Please upgrade to the latest version.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Without confirmation from a credible source, without verifying support

   **Example:** The sentence was unsupported by an inline citation or general bibliographic reference source notes.

   **Source synonyms:** baseless; idle; footless (US); groundless; unfounded; ungrounded; unjustified; unproved; unproven; unsubstantiated; unsupported

<a id="r1-s4"></a>

**Source sense R1.S4**
