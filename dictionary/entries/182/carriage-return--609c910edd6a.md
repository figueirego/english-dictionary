## Noun

### Forms

- carriage returns — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. On a typewriter or computer printer, the action that returns it to the beginning of the next line.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The control character (0x0D in ASCII, abbreviated as CR) that originally signaled a device to perform a carriage return, but now merely indicates the end of a line of text (newline).

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** mul&#58;\\r

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The key or lever that initiates the carriage return action (on a typewriter) or generates the carriage return character (on a computer).
