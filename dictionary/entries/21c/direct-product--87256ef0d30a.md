## Noun

### Forms

- direct products — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The set of all possible tuples whose elements are elements of given, separately specified, sets.

   **Example:** If A and B are sets, their direct product is the set of ordered pairs (a,b) with a in A and b in B.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Such a set of tuples formed from two or more groups, forming another group whose group operation is the component-wise application of the original group operations and of which the original groups are normal subgroups.

   **Source topics (extractor hierarchy; not curated):** group-theory; mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Such a set of tuples formed from two or more rings, forming another ring whose operations arise from the component-wise application of the corresponding original ring operations.

   **Usage:** ring theory

   **Example:** A Boolean ring of order 2ⁿ (or dimension n) may be constructed as the direct product of n Boolean rings of dimension one.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A topological space analogously formed from two or more (up to an infinite number of) topological spaces.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; topology

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Any of a number of mathematical objects analogously derived from a given ordered set of objects.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s6"></a>

**Source sense R1.S6**

6. A high-level generalization of the preceding that applies to objects in an arbitrary category and produces a new object constructable by morphisms from each of the original objects.

   **Source topics (extractor hierarchy; not curated):** category-theory; computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
