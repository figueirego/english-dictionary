### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To return to (an activity).

   **Usage:** transitive

   **Example:** I'll get back to work as soon as I've finished this game.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To return contact with (someone); to return to someone in response to a request.

   **Usage:** transitive

   **Example:** I'll get back to you when I have an answer.

   **Example:** When I'm done with it, I'll get back to you about it.
