**Source sense R1.S1**

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A map which, in any of several technical senses, represents the containment of one structure inside another.
   1. A continuous map which is also a homeomorphism between its domain and its image (considered with the subspace topology induced by its codomain).

      **Source topics (extractor hierarchy; not curated):** mathematics; sciences; topology

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A map which, in any of several technical senses, represents the containment of one structure inside another.
   1. An immersion which is also a topological embedding; equivalently, a diffeomorphism whose image is a submanifold of its codomain.

      **Usage:** differential topology

      **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A map which, in any of several technical senses, represents the containment of one structure inside another.
   1. A ring homomorphism between fields (the name deriving from the fact that all such maps are injective).

      **Usage:** field theory; Galois theory; field theory; Galois theory

      **Source topics (extractor hierarchy; not curated):** mathematics; sciences

**Source sense R1.S5**

5. A map which, in any of several technical senses, represents the containment of one structure inside another.
   1. A map between metric spaces which preserves distances up to some scaling factor (called the distortion).
