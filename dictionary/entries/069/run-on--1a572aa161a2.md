**Source sense R1.S1**

1. To continue without interruption

   **Usage:** idiomatic

   **Example:** We can't afford for the performance to run on for more than the specified time.

2. Using a certain time zone.

   **Example:** I was still running on daylight savings time.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To continue talking for a long time.

   **Usage:** idiomatic

   **Example:** She ran on and wouldn't let anyone get a word in edgeways.

4. To operate with a particular energy source.

   **Example:** This car runs on bio-alcohol.
