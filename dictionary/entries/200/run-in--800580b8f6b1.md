### Senses

<a id="r3-s1"></a>

**Source sense R3.S1**

1. To arrest; (especially) to track down and arrest.

   **Usage:** informal; transitive; chiefly passive voice

   **Example:** The guys who robbed the bank last week have finally been run in.

<a id="r3-s2"></a>

**Source sense R3.S2**

2. To use new machinery at less than full speed, preventing damage.

   **Usage:** UK; transitive

   **Example:** I have to drive slowly for the first 1,000 miles to run the engine in.

   **Source synonyms:** break in

<a id="r3-s3"></a>

**Source sense R3.S3**

3. To start a new regime slowly.

   **Usage:** figuratively

   **Source synonyms:** phase in

   **Source topics (extractor hierarchy; not curated):** ball-games; games; hobbies; lifestyle; rugby; sports
