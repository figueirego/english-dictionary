## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Ready for the oven; already suitably prepared for cooking in an oven.

   **Usage:** literally

   **Example:** an oven-ready chicken

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Ready to be implemented or put into place.

   **Usage:** figuratively

   **Example:** There is no oven-ready solution to this problem.
