### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Drawing upon, invoking, or referring back to itself.

   **Example:** the recursive nature of stories which borrow from each other

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Having to do with an object (typically a function or formula) which is defined in terms of the object itself.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
