### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. For a number x, the exponent by which a given base number must be raised in order to obtain the power x. Written log \_bx. For example, log ₁₀1000=3 because 10³=1000 and log ₂16=4 because 2⁴=16.
