### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A characteristic or quality of a thing.

   **Example:** His finest attribute is his kindness.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An object that is considered typical of someone or some function, in particular as an artistic convention.

   **Example:** The eagle and the bolt of lightning are attributes of Jove.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A word that qualifies a noun.

<a id="r1-s4"></a>

**Source sense R1.S4**

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. An option or setting belonging to some object.

   **Usage:** object-oriented programming

   **Example:** This packet has its coherency attribute set to zero.

   **Example:** A file with the read-only attribute set cannot be overwritten.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
