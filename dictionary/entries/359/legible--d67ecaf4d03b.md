### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Clear enough to be read; readable, particularly of handwriting.

   **Example:** Despite hardly having any energy to lift a pen, she left a legible note on the paper.

   **Source synonyms:** clean; clear; decipherable; fair; readable

   **Source antonyms:** illegible; unreadable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Written or phrased so as to be easy to understand.

   **Example:** You can make this program code more legible by using meaningful variable names.

   **Source synonyms:** clear; decipherable; readable

   **Source antonyms:** unreadable
