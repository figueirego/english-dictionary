### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To increase rapidly to a new value.

   **Usage:** intransitive

   **Example:** Headcount ramped up over three months.

   **Source synonyms:** build up

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To increase (something) rapidly to a new value; to cause (something) to ramp up.

   **Usage:** transitive

   **Example:** The manager ramped up headcount.

   **Source synonyms:** build up

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To start up; to be in an initial phase of rapid increase.

   **Usage:** intransitive

   **Example:** The 5G development project will ramp up in the first quarter.

   **Source synonyms:** fire up; spin up

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To start (something) up; to cause (something) to ramp up.

   **Usage:** transitive

   **Example:** He wants to be first to ramp up his project.

   **Source topics (extractor hierarchy; not curated):** management

   **Source synonyms:** fire up; spin up
