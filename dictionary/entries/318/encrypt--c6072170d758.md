### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To conceal information by means of a code or cipher.

   **Example:** All messages on this platform are doubly encrypted to increase security.

   **Source synonyms:** encode

   **Source antonyms:** decode; decrypt

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To transform information using encryption in a way that it is believed only authorized parties can decode.

   **Example:** The data was encrypted in transit using AES-GCM.
