### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. capable of being decided.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. describing a set for which there exists an algorithm that will determine whether any element is or is not within the set in a finite amount of time.

   **Example:** It is easy to show that the set of even numbers is decidable by creating the relevant Turing machine.

   **Source topics (extractor hierarchy; not curated):** computer; computing; engineering; mathematics; natural-sciences; physical-sciences; science; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. in intuitionistic logic, a proposition P is decidable in a given theory if it can be proven from the theory that "either P or not P", i.e. in symbols&#58; P∨¬P.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences
