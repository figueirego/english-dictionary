### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To hit someone with a car or other vehicle and injure or kill them.

   **Usage:** transitive

   **Example:** He was run down while crossing the main road.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To criticize someone or an organisation, often unfairly.

   **Usage:** transitive

   **Example:** Whatever the company says, the media is going to run them down.

   **Example:** My sister is always running me down in front of my friends.

   **Example:** Don't run yourself down so much!

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To find something or someone after searching for a long time.

   **Usage:** transitive

   **Example:** I finally managed to run down that report. I had filed it incorrectly.

   **Source synonyms:** run to earth; run to ground

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To lose power slowly. Used for a machine, battery, or other powered device.

   **Usage:** intransitive; transitive

   **Example:** You need to wind up the clock every day so that it doesn't run down.

   **Example:** If you don't switch off the car lights, you will run the battery down.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To read quickly a list or other short text.

   **Usage:** transitive

   **Example:** Running down the list of suggestions, I can see three we can discard immediately.

<a id="r1-s6"></a>

**Source sense R1.S6**

6. To describe in the form of a rundown, a rough outline or summary.

   **Usage:** transitive

<a id="r1-s7"></a>

**Source sense R1.S7**

7. To reduce the size or stock levels of a business, often with a view to closure.

   **Usage:** UK; transitive

   **Example:** The board of directors have decided to run down the stocks held in storage prior to offering the company for sale.

   **Example:** Before you move, you should run down your food supplies in the fridge, freezer, and pantry to use up as much as possible.

<a id="r1-s8"></a>

**Source sense R1.S8**

8. To decline in quality or condition.

   **Example:** to run down in health

<a id="r1-s9"></a>

**Source sense R1.S9**

9. To chase till the object pursued is captured or exhausted.

   **Example:** to run down a stag

   **Source topics (extractor hierarchy; not curated):** hobbies; hunting; lifestyle

<a id="r1-s10"></a>

**Source sense R1.S10**

10. To run against and sink, as a vessel.

   **Usage:** transitive

   **Source topics (extractor hierarchy; not curated):** nautical; transport

<a id="r1-s11"></a>

**Source sense R1.S11**

11. To crush; to overthrow; to overbear.

   **Usage:** transitive

<a id="r1-s12"></a>

**Source sense R1.S12**

12. To approach (someone, thing or place) aggressively, as to attack.

   **Usage:** slang; transitive; African-American Vernacular

   **Example:** He ran down on Rashad and them.

<a id="r1-s13"></a>

**Source sense R1.S13**

13. To move (some copy) down to the next line.

   **Usage:** transitive

   **Example:** If they occasionally supply any additional copy after this element, run it down with a manual line break.

   **Source topics (extractor hierarchy; not curated):** media; publishing; typography

<a id="r1-s14"></a>

**Source sense R1.S14**

14. Used other than figuratively or idiomatically&#58; see run, down.
