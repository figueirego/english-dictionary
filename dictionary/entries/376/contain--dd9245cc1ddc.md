### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To hold inside.

   **Usage:** transitive

   **Example:** The brown box contains three stacks of books.

   **Example:** a spray bottle containing water.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To include as a part.

   **Usage:** transitive

   **Example:** Most of the meals they offer contain meat.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To put constraints upon; to restrain; to confine; to keep within bounds.

   **Usage:** transitive

   **Example:** I'm so excited, I can hardly contain myself!

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To have as an element or subset.

   **Usage:** transitive

   **Example:** A group contains a unique inverse for each of its elements.

   **Example:** If that subgraph contains the vertex in question then it must be spanning.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

   **Source context (verbatim):** of a set etc.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To restrain desire; to live in continence or chastity.

   **Usage:** intransitive; obsolete
