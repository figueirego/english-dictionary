### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To rewrite existing source code in order to improve its readability, reusability or structure without affecting its meaning or behaviour.

   **Example:** The code works, but I must refactor it before it is production quality.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To rewrite existing text in order to improve its readability, reusability or structure without intentionally affecting its meaning. Similar to, but sometimes involving more extensive restructuring than, copy editing.

   **Example:** Two significant activities which to contribute to community projects, such as Wikipedia, are to refactor complicated articles into simpler ones, and to refactor duplicated content into reusable templates.
