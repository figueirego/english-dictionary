### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A type of non-volatile random-access rewritable electronic memory using ferrite cores to magnetically store binary digits (bits).

   **Usage:** countable; historical; uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** core; magnetic core memory; ferrite core memory

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A memory, especially one formed in childhood, which recalls a deeply significant event in one's life and can be remembered years later.

   **Usage:** countable; informal

   **Example:** My high school graduation is a core memory.
