## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A data type provided by a programming language as a basic building block, such as integer, character or Boolean.

   **Usage:** idiomatic

   **Example:** Although assembly language has no primitive types in the way that high-level languages do, assemblers do provide directives to allocate and interpret blocks of memory in specific, low-level ways, highly dependent on the target processor architecture, which programmers can think of as being effectively like primitive types.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences

   **Source antonyms:** composite type

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used other than figuratively or idiomatically&#58; see primitive, type&#58; a crude, simplistic, and/or early kind (of a device or physical system).

   **Example:** The television that existed in the 1920s was of a primitive type, but it paved the way for what would come later.
