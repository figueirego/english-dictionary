## Noun

### Forms

- Lebesgue integrals — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An integral which has more general application than that of the Riemann integral, because it allows the region of integration to be partitioned into not just intervals but any measurable sets for which the function to be integrated has a sufficiently narrow range.

   **Usage:** singular; singular-only

   **Example:** The Lebesgue integral is learned in a first-year real-analysis course.

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The result of the application of the Lebesgue integral

   **Usage:** singular; singular-only

   **Example:** Compute the Lebesgue integral of f over E.

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences
