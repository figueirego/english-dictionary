<a id="r1-s1"></a>

**Source sense R1.S1**

1. A group, collection, category or set sharing characteristics or attributes.

   **Usage:** countable

   **Example:** The new Ford Fiesta is set to be best in the 'small family' class.

   **Example:** That is one class-A heifer you got there, sonny.

   **Example:** Often used to imply membership of a large class.

   **Example:** This word has a whole class of metaphoric extensions.

   **Usage:** countable

   **Source topics (extractor hierarchy; not curated):** human-sciences; sciences; social-science; sociology

**Source sense R1.S3**

   **Usage:** uncountable

   **Example:** Jane Austen's works deal with class in 18th-century England.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Admirable behavior; elegance.

   **Usage:** uncountable

   **Example:** Apologizing for losing your temper, even though you were badly provoked, showed real class.

   **Source antonyms:** vulgarity

<a id="r1-s5"></a>

**Source sense R1.S5**

5. A group of students in a regularly scheduled meeting with a teacher.

   **Usage:** countable; uncountable

   **Example:** The class was noisy, but the teacher was able to get their attention with a story.

   **Source topics (extractor hierarchy; not curated):** education

**Source sense R1.S6**

   **Usage:** countable; uncountable

   **Usage:** India; countable; uncountable

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; statistics

**Source sense R1.S14**

14. A collection of sets definable by a shared property, especially one which is not itself a set (in which case the class is called proper).

   **Usage:** countable; uncountable

   **Example:** The class of all sets is not a set.

   **Usage:** countable; object-oriented programming

   **Example:** an abstract base class
