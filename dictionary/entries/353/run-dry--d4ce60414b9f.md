### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To become dry; to cease to flow with water.

   **Usage:** literally

   **Example:** Last summer the river ran dry.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To run out; to be fully consumed; to expire.

   **Usage:** figuratively

   **Example:** The beer soon ran dry so we cracked open a bottle of wine.

   **Example:** I used to write short stories, but these days my inspiration has run dry.
