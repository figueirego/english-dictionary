### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A fault in a digital circuit, where a signal does not change as expected, but remains always in one state.

   **Source topics (extractor hierarchy; not curated):** business; electrical-engineering; electricity; electromagnetism; electronics; energy; engineering; natural-sciences; physical-sciences; physics

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A flag applied to an inode, formerly indicating that an executable program should be kept in memory after it terminates, but on modern systems used to determine which users can rename or delete the files in a directory.
