### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The surroundings of, and influences on, a particular item of interest.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The natural world or ecosystem.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. All the elements that affect a system or its inputs and outputs.

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A particular political or social setting, arena or condition.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. The software or hardware existing on any particular computer system.

   **Example:** That program uses the Microsoft Windows environment.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s6"></a>

**Source sense R1.S6**

6. The environment of a function at a point during the execution of a program is the set of identifiers in the function's scope and their bindings at that point.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences
