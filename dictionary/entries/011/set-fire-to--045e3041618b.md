### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To cause (something) to be on fire; to set (something) alight.

   **Usage:** transitive

   **Example:** They set fire to the house.

   **Source synonyms:** set light; set on fire; torch

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To destroy or dismantle (something).

   **Usage:** figuratively; transitive

   **Example:** As soon as the new CEO arrived, he started setting fire to the old way of doing things.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To stir up intense emotion or action in (something).

   **Usage:** figuratively; transitive

   **Example:** All it took was one word to set fire to the crowd.

   **Source synonyms:** set on fire
