### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. To send a message to; to transmit a message to, e.g. as text via a cell phone.

   **Example:** Just message me for directions.

   **Example:** I messaged her about the concert.

<a id="r2-s2"></a>

**Source sense R2.S2**

2. To send (something) as a message; usually refers to electronic messaging.

   **Example:** She messaged me the information yesterday.

   **Example:** Please message the final report by fax.

<a id="r2-s3"></a>

**Source sense R2.S3**

3. To send a message or messages; to be capable of sending messages.

   **Usage:** intransitive

   **Example:** We've implemented a new messaging service.

   **Example:** The runaway computer program was messaging non-stop.

<a id="r2-s4"></a>

**Source sense R2.S4**

4. To bear as a message.

   **Usage:** obsolete
