## Conjunction

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Indicates result; in order that, with the result that.

   **Example:** He must die so that (as a result) others may/might live.

   **Example:** You so create your own activities that you ﬁnd them fulﬁlling.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Indicates purpose; in such a way that, with the intent that.

   **Example:** He tied a complex knot so that others would find it hard to undo.

   **Example:** I’ll open a window, so that we’ll get some fresh air in here.

   **Example:** So that I'd pass, I studied really hard.
