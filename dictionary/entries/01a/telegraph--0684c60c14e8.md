### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Synonym of telegraphy, any process for transmitting arbitrarily long messages over a long distance using a symbolic code.

   **Usage:** uncommon

   **Example:** This strict sense of telegraph developed from French usage for Napoleon's overland semaphore network but rather arbitrarily excludes similar Chinese and other signalling networks.

   **Source synonyms:** telegraphy (synonym; synonym-of); any process for transmitting arbitrarily long messages over a long distance using a symbolic code (synonym; synonym-of)

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The electrical device gradually developed in the early 19th century to transmit messages (telegrams) using Morse code; the entire system used to transmit its messages including overhead lines and transoceanic cables.

   **Usage:** historical

   **Example:** The first message transmitted by telegraph in the United States was WHAT HATH GOD WROUGHT.

<a id="r1-s3"></a>

**Source sense R1.S3**
