## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Capable of being dismantled, or taken apart.

   **Usage:** not-comparable

   **Source synonyms:** demountable; dismantleable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The property of an ordered set such that its elements can be listed in an order such that, for every element, the element is irreducible (has exactly one upper or lower cover) in the subset consisting of that element and all subsequent elements.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The property of a graph such that its vertices can be listed in an order such that, for every vertex, the vertex is a subdominant vertex (has an adjacent vertex that is adjacent to every other vertex that it is adjacent to) in the induced subgraph generated by that vertex and all subsequent vertices.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences
