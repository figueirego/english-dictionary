## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A code used on DVDs to identify which region's DVD player it will play in.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A code used in DVD players to allow only DVDs being sold in that region to be played.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A two-character code used to identify a region in computer systems.
