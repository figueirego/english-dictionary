### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A value kept constant during an experiment, equation, calculation, or similar, but varied over other versions of the experiment, equation, calculation, etc.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A variable that describes a property or characteristic of some system (material, object, event, etc.) or some aspect thereof.

   **Source topics (extractor hierarchy; not curated):** sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A variable that describes a property or characteristic of some system (material, object, event, etc.) or some aspect thereof.
   1. Any measured quantity of a statistical population that summarises or describes an aspect of the population.

      **Source topics (extractor hierarchy; not curated):** mathematics; sciences; statistics

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A variable that describes a property or characteristic of some system (material, object, event, etc.) or some aspect thereof.
   1. A variable of a model that is trained by a machine learning algorithm.

      **Usage:** machine learning

      **Source topics (extractor hierarchy; not curated):** sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. An input variable of a function definition, that gets an actual value (argument) at execution time.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences

   **Source synonyms:** formal parameter

<a id="r1-s6"></a>

**Source sense R1.S6**

6. An actual value given to such a formal parameter.

   **Usage:** broadly

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences

   **Source synonyms:** argument; actual parameter

<a id="r1-s7"></a>

**Source sense R1.S7**

7. A characteristic or feature that distinguishes something from others.

   **Source synonyms:** attribute; characteristic; designation; vein; distinctiveness; feature; hallmark; owndom (uncommon); parameter; property; propriety (obsolete); quality; race (obsolete); trait; touch; whatness

<a id="r1-s8"></a>

**Source sense R1.S8**

8. In the ellipse and hyperbola, a third proportional to any diameter and its conjugate, or in the parabola, to any abscissa and the corresponding ordinate.

   **Example:** The parameter of the principal axis of a conic section is called the latus rectum.

   **Source topics (extractor hierarchy; not curated):** geometry; mathematics; sciences

**Source sense R1.S10**

   **Source topics (extractor hierarchy; not curated):** chemistry; crystallography; natural-sciences; physical-sciences
