### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Evasive and shifty.

   **Usage:** Commonwealth; Ireland; UK; colloquial

   **Example:** Asked why, a spokesman gave a dodgy answer about legal ramifications.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Unsound and unreliable.

   **Usage:** Commonwealth; Ireland; UK; colloquial

   **Example:** Never listen to dodgy advice.

   **Example:** The dodgy old machine kept breaking down.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Dishonest.

   **Usage:** colloquial

   **Example:** The more money the better, because there is always that dodgy politician or corrupt official to bribe.

   **Example:** I am sure you wouldn't want to be seen buying dodgy gear, would you? (stolen goods).

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Risky.

   **Usage:** colloquial

   **Example:** This is a slightly dodgy plan, because there is a lot that is being changed for this fix.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Deviant.

   **Usage:** colloquial

   **Example:** He's a dodgy Peeping Tom.

<a id="r1-s6"></a>

**Source sense R1.S6**

6. Uncomfortable and weird.

   **Usage:** colloquial

   **Example:** The situation was right dodgy.

   **Example:** I'm feeling dodgy today, probably got the flu.
