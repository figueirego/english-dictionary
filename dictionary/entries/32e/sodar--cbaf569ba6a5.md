### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A system resembling sonar but used in the air, for meteorological measurements, rather than in water.

   **Usage:** uncountable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A type of system using such a method, differentiated by platform, configuration, frequency, power, and other technical attributes.

   **Usage:** countable

<a id="r1-s3"></a>
