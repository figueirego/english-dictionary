### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To perform or repeat an action on each item in a set.

   **Example:** The max() function iterates through the data to find the highest value.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** reiterate; iterate (archaic); reiterate; repeat; reprise

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To perform or repeat an action on the results of each such prior action.

   **Example:** In mathematics, an iterated function is a function which is composed with itself, possibly ad infinitum, in a process called iteration.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To utter or do a second time or many times; to repeat.

   **Usage:** archaic; transitive

   **Example:** to iterate advice

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To repeat an activity, making incremental changes each time.

   **Usage:** ambitransitive

   **Source topics (extractor hierarchy; not curated):** arts; design
