### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The act of saturating or the process of being saturated.

   **Usage:** uncountable; usually

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The condition in which, after a sufficient increase in a causal force, no further increase in the resultant effect is possible; e.g. the state of a ferromagnetic material that cannot be further magnetized.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** natural-sciences; physical-sciences; physics

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The state of a saturated solution.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The state of an organic compound that has no double or triple bonds.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. The smallest set containing S which is saturated with respect to the equivalence relation or function.

   **Usage:** countable; usually

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory; topology

   **Source context (verbatim):** of a set S; with respect to an equivalence relation or function

<a id="r1-s6"></a>

**Source sense R1.S6**

6. The state of the atmosphere when it is saturated with water vapour; 100% humidity.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** climatology; meteorology; natural-sciences

<a id="r1-s7"></a>

**Source sense R1.S7**

7. The intensity or vividness of a colour.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** art; arts

<a id="r1-s8"></a>

**Source sense R1.S8**

8. Chromatic purity; freedom from dilution with white.

   **Usage:** uncountable; usually

<a id="r1-s9"></a>

**Source sense R1.S9**

9. intense bombing of a military target with the aim of destroying it.

   **Usage:** uncountable; usually

<a id="r1-s10"></a>

**Source sense R1.S10**

10. The flooding of a market with all of a product that can be sold.

   **Usage:** uncountable; usually

<a id="r1-s11"></a>

**Source sense R1.S11**

11. An effect on the sound of an electric guitar, used primarily in heavy metal music.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** entertainment; lifestyle; music

<a id="r1-s12"></a>

**Source sense R1.S12**

12. The condition at which a component of the system has reached its maximum traffic-handling capacity, i.e. one erlang per circuit.

   **Usage:** uncountable; usually

   **Source topics (extractor hierarchy; not curated):** communications; electrical-engineering; engineering; natural-sciences; physical-sciences; telecommunications

<a id="r1-s13"></a>

**Source sense R1.S13**

13. The point at which the output of a linear device, such as a linear amplifier, deviates significantly from being a linear function of the input when the input signal is increased.

   **Usage:** uncountable; usually

   **Example:** Modulation often requires that amplifiers operate below saturation.

   **Source topics (extractor hierarchy; not curated):** communications; electrical-engineering; engineering; natural-sciences; physical-sciences; telecommunications
