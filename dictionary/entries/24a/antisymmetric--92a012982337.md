## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Having the property that, for any two distinct elements of S, at least one is not related to the other via R; equivalently, having the property that, for any x, y ∈ S, if both xRy and yRx then x=y.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; order-theory; sciences; set-theory

   **Source context (verbatim):** of a binary relation R on a set S

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Whose sign changes on the application of a matrix transpose or some generalisation thereof&#58;
   1. Whose transpose equals its negative (i.e., Mᵀ = −M);

      **Usage:** not-comparable

      **Source topics (extractor hierarchy; not curated):** linear-algebra; mathematics; sciences

      **Source context (verbatim):** of a matrix; of certain mathematical objects

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Whose sign changes on the application of a matrix transpose or some generalisation thereof&#58;
   1. That changes sign when any two indices are interchanged (e.g., Tᵢⱼₖ = -Tⱼᵢₖ);

      **Usage:** not-comparable

      **Source topics (extractor hierarchy; not curated):** linear-algebra; mathematics; sciences

      **Source context (verbatim):** of a tensor; of certain mathematical objects
