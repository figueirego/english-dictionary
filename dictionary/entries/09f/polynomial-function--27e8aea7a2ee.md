### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any function whose value is the solution of a polynomial; an element of a subring of the ring of all functions over an integral domain, which subring is the smallest to contain all the constant functions and also the identity function. (If the polynomial is multivariate then there is a different identity function corresponding to each variable.)
