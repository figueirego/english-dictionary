## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A writing system used to unambiguously transcribe the sounds of human speech.

   **Example:** International Phonetic Alphabet

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A spelling alphabet&#58; a set of code words used to substitute the names of the letters of the alphabet, usually for clarity of communication when spelling out words.

   **Example:** NATO phonetic alphabet

   **Source synonyms:** spelling alphabet; radio alphabet
