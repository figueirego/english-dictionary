### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The number of arguments or operands a function or operation takes. For a relation, the number of domains in the corresponding Cartesian product.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computer; computing; engineering; human-sciences; logic; mathematics; natural-sciences; philosophy; physical-sciences; science; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computer; computing; engineering; mathematics; natural-sciences; physical-sciences; science; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. the number of arguments (in Lojban grammar called sumti) specified in the definition of a selbri. (the selbri combined with the sumti make up a bridi).

   **Usage:** Lojban; countable; uncountable

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences
