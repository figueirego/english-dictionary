## Noun · Record 1

### Forms

- smoke tests — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A test for leaks involving blowing smoke into a tube or pipe.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A preliminary test on a newly-constructed piece of electronic equipment, consisting simply of the application of electrical power, to make sure that no egregious wiring errors exist which would cause the circuitry to emit smoke, catch fire, explode, etc.

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Such an initial test on some other (not necessarily electronic) system, such as a computer program, again, not to perform any exhaustive tests of functionality, but simply to make sure that the system will not catastrophically fail on activation.

   **Usage:** broadly

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A test to make sure that theatrical smoke will not set off the smoke alarms in a building.
