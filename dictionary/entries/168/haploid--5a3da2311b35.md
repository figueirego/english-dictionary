### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Having the number of chromosomes that a typical gamete has (in the given organism), namely, half the number that a typical somatic cell has (in the given organism).

   **Usage:** broadly; not-comparable

   **Source topics (extractor hierarchy; not curated):** biology; genetics; medicine; natural-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Having the number of chromosomes that a typical gamete has (in the given organism), namely, half the number that a typical somatic cell has (in the given organism).
   1. Having a single set of unpaired chromosomes (which is the number that a typical gamete has in many organisms although not all).

      **Usage:** broadly; not-comparable; strictly

      **Example:** Examples of haploid cells are prokaryotes and the gametes of eukaryotes.

      **Source topics (extractor hierarchy; not curated):** biology; genetics; medicine; natural-sciences; sciences

      **Source synonyms:** monoploid
