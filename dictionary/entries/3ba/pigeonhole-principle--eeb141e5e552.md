### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The theorem which states that any partition of a finite set of n elements into m (&lt; n) subsets (allowing empty subsets) must include a subset with two or more elements; any of certain reformulations concerning the partition of infinite sets where the cardinality of the unpartitioned set exceeds that of the partition (so there is no one-to-one correspondence).

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences
