### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The number of atoms in a molecule.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Synonym of valence (“the combining capacity of an atom, functional group, or radical determined by the number of atoms of hydrogen with which it will unite, or the number of electrons that it will gain, lose, or share when it combines with other atoms, etc.”).

   **Usage:** countable; historical; uncountable

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences

   **Source synonyms:** valence (synonym; synonym-of)

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The state of a system (often a database system) in which either all stages complete or none complete.

   **Usage:** countable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The quality or state of being atomic.

   **Usage:** uncountable
