## Noun

### Pronunciation

- IPA: /pəˈɹɪfɹəsɪs/ — source labels: Canada; UK; US

### Forms

- periphrases — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The use of a longer expression instead of a shorter one with a similar meaning, for example "I am going to" instead of "I will".

   **Usage:** countable; uncountable

   **Source synonyms:** circumlocution; loquaciousness

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Expressing a grammatical meaning (such as a tense) using a syntactic construction rather than morphological marking.

   **Usage:** countable; uncountable

   **Example:** Language learners sometimes use periphrases like "did go" where a native speaker would use "went".

   **Example:** Native speakers use periphrases like "did not go" where a language learner might use "went not".

   **Source topics (extractor hierarchy; not curated):** human-sciences; linguistics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The substitution of a descriptive word or phrase for a proper name (a type of circumlocution).

   **Usage:** countable; rhetoric; uncountable

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The use of a proper name as a shorthand to stand for qualities associated with it.

   **Usage:** countable; rhetoric; uncountable
