### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A thing whose name cannot be remembered; thingamajig, doohickey.

   **Usage:** obsolete

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Any device or machine, especially one whose name cannot be recalled, often either clever or complicated.

   **Example:** He bought a neat new gadget for shredding potatoes.

   **Example:** That's quite a lot of gadgets you have collected. Do you use any of them?

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Any consumer electronics product.

   **Usage:** informal

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A sequence of machine code instructions crafted as part of an exploit that attempts to divert execution to a memory location chosen by the attacker.

   **Usage:** computer security

<a id="r1-s5"></a>

**Source sense R1.S5**

5. A technique for converting a part of one problem to an equivalent part of another problem, used in constructing reductions.

   **Example:** We reduce an instance of 3-SAT to an instance of bird-flock-optimization, using a gadget that converts each conjunctive Boolean clause to a group of birds.

   **Source topics (extractor hierarchy; not curated):** computer; computing; engineering; mathematics; natural-sciences; physical-sciences; science; sciences

<a id="r1-s6"></a>

**Source sense R1.S6**

6. A spring clip attached to the end of a punty in order to grasp the foot of a glass without leaving a bullion while finishing the bowl.

   **Source topics (extractor hierarchy; not curated):** arts; crafts; glassblowing; hobbies; lifestyle
