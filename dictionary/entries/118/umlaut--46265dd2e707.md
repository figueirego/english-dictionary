### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An assimilatory process whereby a vowel is pronounced more like a following vocoid that is separated by one or more consonants.

   **Source topics (extractor hierarchy; not curated):** human-sciences; linguistics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The umlaut process (as above) that occurred historically in Germanic languages whereby back vowels became front vowels when followed by syllable containing a front vocoid (e.g. Germanic lūsiz &gt; Old English lȳs(i) &gt; Modern English lice).

   **Source topics (extractor hierarchy; not curated):** human-sciences; linguistics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A vowel so assimilated.

   **Source topics (extractor hierarchy; not curated):** human-sciences; linguistics; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The diacritical mark ( ¨ ) placed over a vowel when it indicates a (rounded) front vowel

   **Source topics (extractor hierarchy; not curated):** communications; journalism; literature; media; orthography; publishing; writing

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Synonym of diaeresis.

   **Usage:** informal

   **Example:** "Naïve" takes an umlaut because it is pronounced as two syllables.

   **Source topics (extractor hierarchy; not curated):** communications; journalism; literature; media; orthography; publishing; writing

   **Source synonyms:** diaeresis (synonym; synonym-of)
