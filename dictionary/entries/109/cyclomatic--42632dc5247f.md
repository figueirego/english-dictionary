### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Used to describe the number of edges that must be removed from a graph to ensure that no graph cycle remains; equal to the number of edges, minus the number of nodes plus one.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Used to describe the number of circuits in a network; equal to the number of edges, minus the number of nodes plus the number of graphs.

   **Usage:** not-comparable; network analysis

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Of or relating to a software metric that measures the complexity of a program based on the number of linearly independent paths through the source code.

   **Usage:** not-comparable
