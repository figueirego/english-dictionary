### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. That which was stated before, the aforesaid, the above, the same, likewise.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The ditto mark, 〃; a symbol, represented by two apostrophes, inverted commas, or quotation marks (" "), indicating that the item preceding is to be repeated.

   **Source synonyms:** ditto mark; ditto sign; do.; do

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A suit of clothes of the same color throughout.

   **Usage:** historical; in-plural

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A copy made by (run off by) a ditto machine (especially, a worksheet thus reproduced).

   **Usage:** uncommon

   **Example:** Please run off twenty-four dittos of this assignment for my students.

   **Source topics (extractor hierarchy; not curated):** education

<a id="r1-s5"></a>

**Source sense R1.S5**

5. A copy; an imitation.

   **Usage:** broadly
