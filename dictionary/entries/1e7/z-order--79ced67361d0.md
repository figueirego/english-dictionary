### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The order in which objects should be drawn in order to display correctly.

   **Example:** When you click on a window it is brought to the top of the z-order so that you can see it.

   **Source topics (extractor hierarchy; not curated):** computer-graphics; computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A property of a graphical object that indicates its position in the z-order.

   **Example:** To get the rectangle to hide some of the text, make its z-order higher.

   **Source topics (extractor hierarchy; not curated):** computer-graphics; computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
