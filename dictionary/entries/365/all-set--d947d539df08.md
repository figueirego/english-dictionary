## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Ready, prepared, equipped.

   **Usage:** idiomatic; not-comparable

   **Example:** I'm all set to leave for my vacation.

   **Example:** Is everything all set for the wedding?

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Not requiring initial or further assistance with, additions to, or use of something.

   **Usage:** US; not-comparable

   **Example:** "Do you folks want any dessert or coffee?" "No, we're all set."

   **Example:** "Can I use those scissors now?" "Yeah, I'm all set."

   **Example:** Are you all set with that? \[a waiter offering to take an empty plate at a restaurant\]

   **Example:** "Can I help you with anything?" "Nah, I'm all set." \[a retail employee offering to help a customer\]
