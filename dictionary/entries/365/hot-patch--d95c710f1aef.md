### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A patch (software fix) which is applied to a system while it is running, without the need to reboot the system to complete the patching process.

   **Example:** The use of hot patches allows the server to be kept fully up-to-date without any reboot-induced downtime.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A repair for cracks and potholes in a paved surface involving filling them with hot, molten asphalt concrete.

   **Source topics (extractor hierarchy; not curated):** business; construction; manufacturing
