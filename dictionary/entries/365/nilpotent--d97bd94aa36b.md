## Adjective · Record 1

### Pronunciation

- IPA: /nɪlˈpəʊtənt/ — variety unspecified in the source labels

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Such that, for some positive integer n, xⁿ = 0.

   **Usage:** not-comparable; ring theory

   **Example:** If a square matrix is upper triangular and has zeros on the diagonal, then it is nilpotent (under the usual matrix multiplication).

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

   **Source context (verbatim):** of an element x of a ring

<a id="r1-s2"></a>

**Source sense R1.S2**

2. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Belonging to the derived algebra of L and such that the adjoint action of x is nilpotent (as a linear transformation on L).

      **Usage:** not-comparable; Lie theory

      **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

      **Source context (verbatim):** of an element x of a Lie algebra L

<a id="r1-s3"></a>

**Source sense R1.S3**

3. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Such that the lower central series terminates.

      **Usage:** not-comparable; Lie theory

      **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

      **Source context (verbatim):** of a Lie algebra

<a id="r1-s4"></a>

**Source sense R1.S4**

4. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Admitting a central series of finite length.

      **Usage:** not-comparable

      **Source topics (extractor hierarchy; not curated):** algebra; group-theory; mathematics; sciences

      **Source context (verbatim):** of a group

<a id="r1-s5"></a>

**Source sense R1.S5**

5. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Such that there exists a natural number k with Iᵏ = 0.

      **Usage:** not-comparable; ring theory

      **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

      **Source context (verbatim):** of an ideal I

<a id="r1-s6"></a>

**Source sense R1.S6**

6. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Containing only nilpotent elements.

      **Usage:** not-comparable; semigroup theory

      **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

      **Source context (verbatim):** of a semigroup with zero

<a id="r1-s7"></a>

**Source sense R1.S7**

7. In any of several technical senses&#58; behaving analogously to nilpotent ring elements as an element of some other algebraic structure; composed of elements displaying such behavior.
   1. Such that there exists some natural number n (called the index of the algebra) such that all products (of elements in the given algebra) of length n are zero.

      **Usage:** not-comparable

      **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

      **Source context (verbatim):** of an algebra over a commutative ring
