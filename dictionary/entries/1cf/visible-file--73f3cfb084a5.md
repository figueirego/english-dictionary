### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A pre-computer filing method in which cards are arranged in shallow drawers so that a portion of each card is always visible, allowing for quick scanning and retrieval; it uses an overlapping design to make the information on each card accessible without needing to pull it out completely.

   **Source synonyms:** Kardex; visible filing system
