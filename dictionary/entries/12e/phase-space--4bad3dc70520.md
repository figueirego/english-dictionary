### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Given a (dynamical) system, any topological space such that every point in the space's underlying set uniquely represents a state of the system and every possible state is represented by some point;

   **Usage:** countable; uncountable; dynamical system theory

   **Example:** For mechanical systems, the phase space usually consists of all possible values of position and momentum variables.

   **Source topics (extractor hierarchy; not curated):** mathematics; natural-sciences; physical-sciences; physics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Given a (dynamical) system, any topological space such that every point in the space's underlying set uniquely represents a state of the system and every possible state is represented by some point; (less formally) the underlying set of such a topological space.
   1. the underlying set of such a topological space.

      **Usage:** countable; uncountable; dynamical system theory; less formally
