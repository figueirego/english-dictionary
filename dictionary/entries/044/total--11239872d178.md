### Senses

<a id="r3-s1"></a>

**Source sense R3.S1**

1. To add up; to calculate the sum of.

   **Usage:** transitive

   **Example:** When we totalled the takings, we always got a different figure.

   **Source synonyms:** sum

<a id="r3-s2"></a>

**Source sense R3.S2**

   **Example:** That totals seven times so far.

   **Source synonyms:** make

<a id="r3-s3"></a>

**Source sense R3.S3**

3. To demolish; to wreck completely. (from total loss)

   **Usage:** US; slang; transitive

   **Example:** Honey, I’m OK, but I’ve totaled the car.

   **Source synonyms:** demolish; trash; wreck

<a id="r3-s4"></a>

**Source sense R3.S4**

4. To amount to; to add up to.

   **Usage:** intransitive

   **Example:** It totals nearly a pound.
