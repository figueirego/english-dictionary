## Proper noun

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A principle that states that once an interface has become too large, it needs to be split into smaller and more specific interfaces so that any client of the interface will only know about the methods that pertain to itself. In other words, no client should be forced to depend on methods it does not use.

   **Usage:** object-oriented programming
