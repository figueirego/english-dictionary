### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The prefix a- (or an- when prefixing a root which begins with a vowel) found in some English words of Greek derivation. It expresses negation or absence. The prefix has cognates in other Indo-European languages, including in- in Latin and un- in English, all traceable back to Proto-Indo-European \*n̥-.

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

   **Source synonyms:** alpha privativum; privative a

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Either the aforementioned privative a or the Greek ἀ- (a-) itself (from which the English descendant derives).

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

   **Source synonyms:** alpha privativum

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A word formed using such prefixes.
