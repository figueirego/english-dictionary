### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A parameter of a prior (as distinguished from inferred parameters of the model for the underlying system under analysis).

   **Usage:** Bayesian statistics

   **Example:** this model has four hyperparameters

   **Source synonyms:** superparameter

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A parameter whose value is set before the learning process begins.

   **Usage:** machine learning
