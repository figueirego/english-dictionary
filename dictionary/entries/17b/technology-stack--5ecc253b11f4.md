## Noun

### Forms

- technology stacks — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A collection of interdependent existing technologies and methods used to create a particular product or service.

   **Example:** The PHP programming language is part of the technology stack of many interactive websites.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The collection of technologies that one can use in a professional setting.

   **Example:** The Lua programming language is part of the technology stack of many games developers.
