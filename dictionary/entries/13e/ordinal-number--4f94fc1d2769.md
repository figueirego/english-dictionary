## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A word that expresses the relative position of an item in a sequence.

   **Example:** First, second and third are the ordinal numbers corresponding to one, two and three.

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A natural number used to denote position in a sequence.

   **Example:** In the expression a₃, the "3" is an ordinal number.

   **Source topics (extractor hierarchy; not curated):** arithmetic

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Such a number generalised to correspond to any cardinal number (the size of some set); formally, the order type of some well-ordered set of some cardinality a, which represents an equivalence class of well-ordered sets (exactly those of cardinality a) under the equivalence relation "existence of an order-preserving bijection".

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory
