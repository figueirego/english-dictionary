<a id="r1-s2"></a>

**Source sense R1.S2**

2. To connect, set up or prepare something for use
   1. To transfer software onto a device's permanent storage and put it in a state where it is ready to be run when needed, usually decompressing it if necessary and performing any necessary pre-first-run configuration.

      **Usage:** transitive

      **Example:** I haven't installed the new operating system yet because of all the bugs.

      **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To admit formally into an office, rank or position.

   **Usage:** transitive

   **Example:** He was installed as Chancellor of the University.

   **Source synonyms:** seat; instate

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To establish or settle in.

   **Usage:** reflexive; sometimes; transitive

   **Example:** I installed myself in my usual chair by the fire.
