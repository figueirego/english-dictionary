### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An outline or image universally applicable to a general conception, under which it is likely to be presented to the mind (for example, a body schema).

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A formal description of the structure of a database&#58; the names of the tables, the names of the columns of each table, and the data type and other attributes of each column.

   **Example:** The database schema defines how the tables are organized.

   **Source topics (extractor hierarchy; not curated):** computing; databases; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A formal description of data, data types, and data file structures, such as XML schemas for XML files.

   **Usage:** markup languages

<a id="r1-s4"></a>

**Source sense R1.S4**

4. A formula in the metalanguage of an axiomatic system, in which one or more schematic variables appear, which stand for any term or subformula of the system, which may or may not be required to satisfy certain conditions.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. A monastic habit in the Greek Orthodox Church.

   **Source topics (extractor hierarchy; not curated):** Christianity
