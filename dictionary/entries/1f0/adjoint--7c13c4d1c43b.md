### Pronunciation

### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. The transpose of the cofactor matrix of a given square matrix.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r2-s2"></a>

**Source sense R2.S2**

2. Transpose conjugate.

   **Source topics (extractor hierarchy; not curated):** linear-algebra; mathematics; sciences

   **Source context (verbatim):** of a matrix

<a id="r2-s3"></a>

**Source sense R2.S3**

3. Hermitian conjugate.

   **Source topics (extractor hierarchy; not curated):** mathematical-analysis; mathematics; sciences

   **Source context (verbatim):** of an operator

<a id="r2-s4"></a>

**Source sense R2.S4**

4. A functor related to another functor by an adjunction.

   **Source topics (extractor hierarchy; not curated):** category-theory; computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r2-s5"></a>

**Source sense R2.S5**

5. A curve A such that any point of a given curve C of multiplicity r has multiplicity at least r–1 on A. Sometimes the multiple points of C are required to be ordinary, and if this condition is not satisfied the term sub-adjoint is used.

   **Source topics (extractor hierarchy; not curated):** algebraic-geometry; geometry; mathematics; sciences

<a id="r2-s6"></a>

**Source sense R2.S6**

6. An assistant to someone who holds a position in the military or civil service.

<a id="r2-s7"></a>

**Source sense R2.S7**

7. An assistant mayor of a French commune.
