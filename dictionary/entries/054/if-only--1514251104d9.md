## Conjunction

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Used other than figuratively or idiomatically&#58; see if, only.

   **Example:** It made me feel better, if only for a moment.

   **Example:** It won't be much fun if only guys turn up to the party.

<a id="r1-s2"></a>

**Source sense R1.S2**

2. I wish that; would (that) (archaic). Signifies a wish or desire for the present or the future.

   **Usage:** idiomatic

   **Example:** If only I could win the lottery.

   **Example:** My gambling ex could come to his senses, if only.

   **Source synonyms:** that (literary)

<a id="r1-s3"></a>

**Source sense R1.S3**

3. I wish that; would (that) (archaic). Signifies a regret about an action in the past.

   **Usage:** idiomatic

   **Example:** If only I had listened to my parents.

   **Example:** We didn't have that luxury. If only!

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Even if for no other reason than; only just.

   **Usage:** idiomatic

   **Example:** I was pretty sure what I wanted, but I still tried on another if only to make sure.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Signifies a hypothetical or wishful precondition, or one which would be simple but is nonetheless unlikely, for a hypothetical, counterfactual, or future outcome.

   **Usage:** idiomatic

   **Example:** He could be a great student if only he got \[or&#58; if he only got\] a little non-judgmental encouragement.

   **Example:** If you'd only quit interrupting me, I'll tell you!
