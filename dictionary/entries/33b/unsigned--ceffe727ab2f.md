## Adjective · Record 1

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Not accepting negative numbers; having only a positive value (or zero).

   **Usage:** not-comparable

   **Example:** We use an unsigned variable to store the employee's salary, since it will never be less than zero.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Lacking a signature, unendorsed.

   **Usage:** not-comparable

   **Example:** The bank rejected the unsigned check.

<a id="r1-s3"></a>

**Source sense R1.S3**
