### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A commonly used, non-systematic name of a chemical compound. Trivial names for many compounds have been in use since long before their exact chemical structures were determined.

   **Source topics (extractor hierarchy; not curated):** chemistry; natural-sciences; physical-sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A non-systematic name for a chemical element (see systematic element name).

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A commonly used, non-systematic name for an organism.

   **Source topics (extractor hierarchy; not curated):** biology; natural-sciences
