### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Describing a circuit or component that changes its state only when an input signal becomes low.

   **Usage:** not-comparable

   **Example:** Master-slave flip-flops tend to be negative-edge-triggered; however, the clock input can be inverted in order to make the master-slave flip-flop be positive-edge-triggered.
