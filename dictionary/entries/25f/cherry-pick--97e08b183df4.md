### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To pick out the best or most desirable items from a list or group, especially to obtain some advantage or to present something in the best possible light.

   **Usage:** idiomatic

   **Source synonyms:** cull

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To select only evidence which supports an argument, and reject or ignore contradictory evidence.

   **Usage:** broadly; rhetoric

   **Example:** From all the available statistics, the politician cherry-picked only those that backed up his ideas.

   **Source topics (extractor hierarchy; not curated):** human-sciences; logic; mathematics; philosophy; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To position oneself near the opponent's goal to attempt to receive an errant or intentional pass for an easy score, as in basketball or versions of soccer where offsides are not enforced.

   **Usage:** US; idiomatic

   **Source topics (extractor hierarchy; not curated):** hobbies; lifestyle; sports

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To broadcast selected programming from another network.

   **Usage:** US; idiomatic

   **Source topics (extractor hierarchy; not curated):** broadcasting; media

<a id="r1-s5"></a>

**Source sense R1.S5**

5. In source control, to commit selected changes from one branch to another.
