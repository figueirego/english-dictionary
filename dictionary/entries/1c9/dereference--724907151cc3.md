### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. To access the value or object located in a memory location addressed by a pointer or another value interpreted as such; to access a value being referenced by something else.

   **Example:** Attempting to dereference a null pointer often results in a crash.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; programming; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. To operate on the file or directory pointed to by a symbolic link, rather than on the link itself.

   **Example:** With the find command, any symbolic links appearing after -follow will be dereferenced.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** follow; resolve

<a id="r1-s3"></a>

**Source sense R1.S3**

3. To dissolve a symbolic link by replacing it with a copy of its target.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
