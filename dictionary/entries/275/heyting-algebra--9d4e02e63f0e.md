### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A bounded lattice, L, modified to serve as a model for a logical calculus by being equipped with a binary operation called "implies", denoted → (sometimes ⊃ or ⇒), defined such that (a→b)∧a ≤ b and, moreover, that x = a→b is the greatest element such that x∧a ≤ b (in the sense that if c∧a ≤ b then c ≤ a→b).

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; order-theory; sciences
