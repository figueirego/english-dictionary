### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any nonzero commutative ring in which the product of nonzero elements is nonzero.

   **Usage:** ring theory

   **Example:** A ring R is an integral domain if and only if the polynomial ring R\#91;x\#93; is an integral domain.

   **Example:** For any integral domain there can be derived an associated field of fractions.
