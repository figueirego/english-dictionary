### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Of a married or engaged person, to run away from home with a paramour.

   **Usage:** intransitive

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Of an unmarried person, to run away secretly for the purpose of getting married with one's intended spouse; to marry in a quick or private fashion, especially without a public period of engagement.

   **Usage:** intransitive

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Of an unmarried person, to run away secretly from home in order to get married without parental or guardian consent.

   **Usage:** dated; intransitive

   **Source synonyms:** abscond; run away

<a id="r1-s4"></a>

**Source sense R1.S4**

4. To escape from one's caretaker.

   **Usage:** mental health

   **Example:** Six-year-old Casey eloped during recess and police found him watching traffic lights at the intersection.

<a id="r1-s5"></a>

**Source sense R1.S5**

5. To run away from home (for any reason).

   **Usage:** dated; intransitive
