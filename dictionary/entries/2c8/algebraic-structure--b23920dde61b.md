## Noun

### Forms

- algebraic structures — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Any one of the numerous types of mathematical object studied in algebra and especially in universal algebra.

   **Usage:** universal

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A mathematical object comprising a carrier set (aka underlying set or domain), an optional scalar set, a set of operations (typically binary operations, but otherwise each of finite arity) and a set of identities (axioms) which the operations must satisfy.

   **Usage:** more formally

   **Example:** The definition of algebraic structure establishes a framework through which to compare otherwise very different abstract objects, and to study similarities and patterns made apparent by the definition.
