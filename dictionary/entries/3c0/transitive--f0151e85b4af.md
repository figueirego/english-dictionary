### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Making a transit or passage.

   **Usage:** not-comparable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Affected by transference of signification.

   **Usage:** not-comparable

<a id="r1-s3"></a>

**Source sense R1.S3**

3. Taking a direct object or objects.

   **Usage:** not-comparable

   **Example:** The English verb "to notice" is a transitive verb, because we say things like "She noticed a problem".

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

   **Source context (verbatim):** of a verb

   **Source antonyms:** intransitive

<a id="r1-s4"></a>

**Source sense R1.S4**

4. Having the property that if an element a is related to b and b is related to c, then a is necessarily related to c.

   **Usage:** not-comparable

   **Example:** "Is an ancestor of" is a transitive relation&#58; if Alice is an ancestor of Bob, and Bob is an ancestor of Carol, then Alice is an ancestor of Carol.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; set-theory

   **Source context (verbatim):** of a relation on a set

   **Source antonyms:** intransitive; nontransitive

<a id="r1-s5"></a>

**Source sense R1.S5**

5. Such that, for any two elements of the acted-upon set, some group element maps the first to the second.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences

   **Source context (verbatim):** of a group action

<a id="r1-s6"></a>

**Source sense R1.S6**

6. Such that, for any two vertices there exists an automorphism which maps one to the other.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** graph-theory; mathematics; sciences

   **Source context (verbatim):** of a graph

<a id="r1-s7"></a>

**Source sense R1.S7**

7. Of a set of dice&#58; not having the intransitive property.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** mathematics; probability; sciences
