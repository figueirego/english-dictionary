### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. A portable hand tool that combines several individual functions in a single assembly or body.

<a id="r2-s2"></a>

**Source sense R2.S2**

2. A portable hand tool that combines several individual functions in a single assembly or body.
   1. A Swiss Army knife or similar tool.

<a id="r2-s3"></a>

**Source sense R2.S3**

3. A portable hand tool that combines several individual functions in a single assembly or body.
   1. Any of a class of folding or telescoping tools with a plier head as the central implement and with sets of peripheral implements (typically knife blades, screwdrivers, files, saws, can openers, bottle openers, scissors, and so on).

<a id="r2-s4"></a>

**Source sense R2.S4**

4. A portable hand tool that combines several individual functions in a single assembly or body.
   1. Any similar tool with some other central implement (such as shears) or with no central implement, but sharing the themes otherwise.

<a id="r2-s5"></a>

**Source sense R2.S5**

5. A portable hand tool that combines several individual functions in a single assembly or body.
   1. Any of a class of monolithic tools with various holes and edges that act as the multiple implements.

<a id="r2-s6"></a>

**Source sense R2.S6**

6. An oscillating power tool that can perform multiple functions with different attachments.

   **Source synonyms:** oscillating tool
