### Senses

**Source sense R1.S1**

1. Any one of a certain set of numbers which are guaranteed to exist by Ramsey's theorem; a positive integer which is a certain function of some given multiset of positive integers, where that "certain function" is that which yields the minimal number guaranteed to exist by Ramsey's theorem.
