## Noun · Record 1

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A feature of a graphical user interface whereby the user can move or copy an object by dragging its visual representation across the screen and releasing it in another location.

   **Usage:** attributive; uncountable; usually

   **Source topics (extractor hierarchy; not curated):** computing; engineering; graphical-user-interface; mathematics; natural-sciences; physical-sciences; sciences

   **Source synonyms:** drag-drop
