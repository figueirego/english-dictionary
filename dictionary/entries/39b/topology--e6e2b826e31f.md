### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The branch of mathematics dealing with those properties of a geometrical object (of arbitrary dimensionality) that are unchanged by continuous deformations (such as stretching, bending, etc., without tearing or gluing).

   **Usage:** uncountable

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Any collection τ of subsets of a given set X that contains both the empty set and X, and which is closed under finitary intersections and arbitrary unions.

   **Usage:** countable; uncountable

   **Example:** A set X equipped with a topology \#92;tau is called a topological space and denoted (X,\#92;tau).

   **Example:** The subsets of a set X which constitute a topology are called the open sets of X.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences; topology

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The anatomical structure of part of the body.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** medicine; sciences

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The arrangement of nodes in a communications network.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s5"></a>

**Source sense R1.S5**

5. The properties of a particular technological embodiment that are not affected by differences in the physical layout or form of its application.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** engineering; natural-sciences; physical-sciences; technology

<a id="r1-s6"></a>

**Source sense R1.S6**

6. The topographical study of geographic locations or given places in relation to their history.

   **Usage:** countable; uncountable

   **Source topics (extractor hierarchy; not curated):** geography; natural-sciences; topography

<a id="r1-s7"></a>

**Source sense R1.S7**

7. The art of, or method for, assisting the memory by associating the thing or subject to be remembered with some place.

   **Usage:** countable; dated; uncountable
