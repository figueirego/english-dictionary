## Adjective

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Having the property that every subcategory is in the set of orthogonal subcategories of every higher order subcategory.

   **Usage:** not-comparable

   **Source topics (extractor hierarchy; not curated):** category-theory; computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Either columnwise orthogonal (having the property that M'M is an identity matrix) or rowwise orthogonal (having the property that MM' is an identity matrix).

   **Usage:** not-comparable; matrix algebra

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

   **Usage:** not-comparable
