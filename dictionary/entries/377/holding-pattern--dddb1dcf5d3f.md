## Noun

### Forms

- holding patterns — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A path taken by an aircraft waiting to land.

   **Example:** The plane flew in a holding pattern for half an hour because one runway was closed.

   **Source topics (extractor hierarchy; not curated):** aeronautics; aerospace; aviation; business; engineering; natural-sciences; physical-sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Any failure to advance; useless or unproductive activity.

   **Usage:** idiomatic

   **Example:** This project is in a holding pattern until all the parts arrive.
