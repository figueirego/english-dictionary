## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. Printed type which is set with extra leading in such a way as to give the text greater emphasis.

   **Usage:** historical; uncountable; usually

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Printed type in general, as opposed to engravings or handwritten documents.

   **Usage:** historical; uncountable; usually
