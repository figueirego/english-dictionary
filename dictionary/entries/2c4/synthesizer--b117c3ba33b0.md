### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. An electronic musical instrument that creates its sounds with electronics and generally is played via a keyboard.

   **Source topics (extractor hierarchy; not curated):** entertainment; lifestyle; music

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An electronic instrument consisting of a module, or a set of modules, that creates its sounds with electronics and does not have any keyboard.

   **Source topics (extractor hierarchy; not curated):** entertainment; lifestyle; music

<a id="r1-s3"></a>

**Source sense R1.S3**

3. An electronic circuit that generates an electronic signal oscillation with accurate timing from a reference oscillator.

   **Source topics (extractor hierarchy; not curated):** business; electrical-engineering; electricity; electromagnetism; electronics; energy; engineering; natural-sciences; physical-sciences; physics

<a id="r1-s4"></a>

**Source sense R1.S4**

4. An electronic device that generates electronic signal patterns to test an electronic circuit.

   **Source topics (extractor hierarchy; not curated):** business; electrical-engineering; electricity; electromagnetism; electronics; energy; engineering; natural-sciences; physical-sciences; physics

<a id="r1-s5"></a>

**Source sense R1.S5**

5. A software program that allows a computer to be used as a musical instrument – virtual instrument

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences; software
