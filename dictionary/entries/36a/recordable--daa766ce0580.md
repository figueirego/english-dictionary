### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. That can be recorded; capturable.

   **Example:** Sound and movement are recordable by means of microphones and cameras.

   **Example:** User actions are recordable in a macro for playback at a later time.

   **Source antonyms:** erasable; unrecordable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. Able to be used to record something.

   **Source context (verbatim):** of a CD

<a id="r1-s3"></a>
