## Noun

### Forms

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A function whose formula is always the same, but whose initial value is chosen at random from a set of possible values (its domain).

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. A function chosen at random from a set of functions.

   **Source topics (extractor hierarchy; not curated):** mathematics; sciences

<a id="r1-s3"></a>

**Source sense R1.S3**

3. A function that returns a random or pseudo-random value that is distributed according to a specific probability distribution associated with the function.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences
