### Senses

<a id="r2-s1"></a>

**Source sense R2.S1**

1. To bundle third-party dependencies with the source code for one's own program.

   **Usage:** transitive

   **Example:** I distributed my application with a vendored copy of Perl so that it wouldn't use the system copies of Perl where it is installed.

   **Source topics (extractor hierarchy; not curated):** computing; engineering; mathematics; natural-sciences; physical-sciences; sciences; software

<a id="r2-s2"></a>

**Source sense R2.S2**

   **Usage:** transitive

   **Example:** Strawberry Perl contains vendored copies of some CPAN modules, designed to allow them to run on Windows.
