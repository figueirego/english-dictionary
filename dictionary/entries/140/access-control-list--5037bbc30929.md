**Source sense R1.S1**

1. A security scheme for file-level security (as opposed to traditional user, group levels, or the somewhat stricter role levels). Abbreviated ACL.

   **Example:** The hackers broke through the B security model, so no more role-level security&#58; all critical data must use access control lists from now on.
