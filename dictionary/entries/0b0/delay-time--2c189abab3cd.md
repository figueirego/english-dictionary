## Noun

### Forms

- delay times — plural

### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. The amount of time required for a signal to travel through a specific path or component in an integrated circuit.

   **Usage:** countable; uncountable

<a id="r1-s2"></a>

**Source sense R1.S2**

2. The elapsed time between the change of a component at the reference point and a system response of 10% of the final reading.

   **Usage:** countable; uncountable

<a id="r1-s3"></a>

**Source sense R1.S3**

3. The time interval between a reference point on one waveform and a reference point on another waveform.

   **Usage:** countable; uncountable

<a id="r1-s4"></a>

**Source sense R1.S4**

4. The time interval between a transition at an input and a resultant change at an output.

   **Usage:** countable; uncountable
