### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A sequence which describes the visual composition of a Chinese character; comprised of a ideographic description character that gives a layout (e.g. ⿰, ⿸) or transformation (e.g. ⿿), followed by one or more components which that character operates on, which may be encoded characters or other sequences in the same format.

   **Usage:** Unicode
