### Senses

<a id="r1-s1"></a>

**Source sense R1.S1**

1. A grammatical number denoting a quantity of exactly two.

   **Source topics (extractor hierarchy; not curated):** grammar; human-sciences; linguistics; sciences

<a id="r1-s2"></a>

**Source sense R1.S2**

2. An element of an algebra (the algebra of dual numbers) which includes the real numbers and an element ε which satisfies ε ≠ 0 and ε² = 0.

   **Example:** If f(x) is a polynomial or a power series then its derivative can be obtained “automatically” using dual numbers as follows&#58; f'(x)\#61;\#123;f(x\#43;\#92;epsilon)-f(x)\#92;over\#92;epsilon\#125; where f(x\#43;\#92;epsilon) should be expanded using the algebra of dual numbers. The role of the ε is therein similar to that of an infinitesimal.

   **Source topics (extractor hierarchy; not curated):** algebra; mathematics; sciences
